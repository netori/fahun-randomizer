START快速上手（8 步）

第一次用照着走一遍就行。全程只点界面里的按钮，不需要装 mod 管理器，也不需要改游戏文件。

  1. 放好 exe：把 ConvergenceClassItemRandomizer.exe 放进法魂整合包里「和 mod 文件夹、启动法魂.bat 并排」的那一层。
  2. 双击打开：第一次启动会在 exe 旁边生成 investigation 文件夹（别删）。等「本地文件」自检跑完；缺「原始备份」就点 补一份原始备份。
  3. 勾要随机的类型：页签标题前的勾选框 —— 勾「职业物品随机」/「敌人随机」，或者两个都勾（底部按钮会变成「开始随机物品和敌人」）。
  4. 物品页先只调一件事：合理度保持 80%。随机项目至少勾一项（卢恩 / 护甲 / 装备）。第一次不用动「更多设置」。
  5. 敌人页先选预设：配置选 01 参考默认·同族池；四个特殊池保持默认全开；其它开关先不动。
  6. 点底部主按钮：开始随机物品和敌人。它会生成一套方案并自动存进方案库，同时跳到方案库页。
  7. 双击刚生成的那一行：第一次开玩会先生成覆盖层（只物品几十秒；含敌人约 3 分钟）→ 换档 → 挂载 → 起游戏。
  8. 想回原版：退出游戏，点 切回法魂本体（只是不挂层）。本体从来没被动过，不用还原。
一句话记住流程：「开始随机」= 造一套方案，不写游戏文件；「双击方案」= 生成覆盖层并开玩。方案可以存很多套，互不覆盖。

01认识它

这是一个给《艾尔登法环》法魂汉化整合包（游戏 1.17.1）用的单机随机器，两个玩法：

职业物品随机

把游戏里本来就存在的物品出现位置重洗：宝箱 / 掉落里放什么、职业说明书里写的地点、可选把商店在售的职业专属装备一起换。

不新增物品，不改物品名 / 数量 / 概率 / 价格 / 解锁条件。

敌人随机

把地图上摆着的敌人换成别的敌人：普通杂兵、野生生物、BOSS 都能按规则互换；可改 BOSS 血条名、按区域强度缩放换入者。

改的是克隆行，原 NpcParam 一行不动；地图布局、事件流程也不动。

它为什么敢说「本体一个字节都不改」

因为所有产物都落在方案层里，而不是写回法魂本体：

  • 每次随机 = 一套方案（存在 plans\ 里的 JSON：设置 + 种子 + 计划 + 版本指纹）；
  • 开玩时才按方案生成覆盖层：法魂包\方案\<层名>\mod\，里面是 regulation.bin、说明书、地图、事件等一整套文件；
  • 启动器把这一层「盖」在法魂本体上（yafsml\YAFSML.ini 里的 Plan= 一行），游戏读到的是层里的文件；
  • 不玩了就删掉挂载（切回法魂本体）—— 法魂本体那份 mod\regulation.bin 始终是原样。

先用之前知道三件事：① 只能单人离线玩，不能联机；② 玩多套方案前先关掉 Steam 云存档；③ 用前请自己备份一份存档。工具不联网，未签名的 exe 被杀软提示属正常。

02安装与第一次运行

2.1 需要准备什么

  • Windows；《艾尔登法环》法魂汉化本体 1.17.1（新版 YAFSML 启动器）整合包；
  • 随机器 ConvergenceClassItemRandomizer.exe（发行包解压即得）；
  • 建议：整合包原版 regulation.bin 的一份备份（工具也会自己留，但自己留一份最稳）；
  • 不需要 mod 管理器；不需要联网。

2.2 放在哪里

判据只有一条：exe 所在层（或往上一两层）里有 mod\regulation.bin。最省事的摆法是把 exe 直接放在法魂整合包根目录：

法魂整合包\
├─ mod\regulation.bin          ← 法魂本体（工具永远不写这里）
├─ yafsml\YAFSML.ini           ← 启动器配置（Plan= 挂载开关在这里）
├─ 启动法魂.bat
├─ ConvergenceClassItemRandomizer.exe   ← 把 exe 放这一层
├─ investigation\              ← 第一次运行自动生成（原始备份、预设、手工表都在里面）
├─ plans\                      ← 方案库（每次随机自动保存）
├─ 方案\                       ← 每次开玩生成的覆盖层
└─ 存档库\                     ← 每套方案自己的独立存档

找不到也不要紧：打开程序点 指定 MOD 目录… 手动选一次即可；以后整个文件夹搬到别的盘 / 改名，它会按「哪层有 mod\regulation.bin」重新找。

2.3 第一次运行：本地文件自检

第一次打开会在 exe 旁边生成工作文件（几秒）。「本地文件」卡会逐项检查，缺必需项会禁用开始按钮：

检查项它在确认什么缺了怎么办

说明书基准说明书基线是否登记同「原始备份」一起补

其它按钮：重新检测 重跑一遍；逐项详情▸ 展开看每一项的实际路径与错误原因。

2.4 第一次运行的两个小坑

  • 别删 investigation 文件夹：原始备份在 investigation\apply\backup，删了之后「还原成原始」就没有基线了。
  • 报找不到 oo2core_*_win64.dll：打开游戏安装目录里的 Game 文件夹，把 oo2core_*_win64.dll 复制到 exe 旁边的 oodle 文件夹（没有就新建）。放一次即可。
「原始备份」必须是真的原版。如果第一次补备份时本体已经被随机过（比如用过 2026-10-23 之前「直接写本体」的老版本），工具会拒绝登记或写入时提示「写前复核未通过」。处理：把法魂 mod 原版 regulation.bin 放回本体 → 再点「补一份原始备份」。

04物品随机

把「什么东西、在哪儿」重新洗一遍。你只需要做四个决定：随机什么 → 怎么混 → 允许多乱（合理度） → 要不要动商店。

4.1 先看懂这张卡片上的四步

  1. 第 1 步 · 随机项目：卢恩 / 护甲 / 装备（武器）—— 至少勾一项；勾几项，下面就决定怎么混。
  2. 第 2 步 · 合理度：一个滑杆同时管「最远跨几档 / 多少东西真的跨档 / 武器掺进混池的上限」。第一次保持 80%。
  3. 更多设置（默认折叠）：法祷整套一起换 / 说明书跟着改 / 商店参与 / 改动比例。第一次可以先不看。
  4. 点底部主按钮：生成方案 → 自动存进方案库 → 跳到方案库。这一步不碰任何游戏文件。
生成不是写入。物品方案生成后只是一个 JSON；真正的物品数据是在「开玩」生成覆盖层时才写进 法魂包\方案\<层名>\mod\ 的，法魂本体不参与。

方式意思适合

4.3 合理度：一个滑杆，三件事

1. 最远跨几档

物品按等级/强度分档。合理度越高，越倾向「同档位互换」；越低，越可能抽到跨度大的东西。

2. 多少东西真的跨档

越档不是不可能，而是按概率发生：越档率 ≈ 100% − 合理度。80% ⇒ 最多约 20% 的位置会跨出允许的跨度。

3. 武器掺进混池的上限

混池里武器占比有硬上限 66%，不会出现「一池子全是武器」。

合理度档位跨度越档率手感
100%1/4 · 只能同档位互换0%最保守，基本只换同强度物品
80%（默认）2/4 · 相邻两档可互换≤ 20%推荐第一次就用这个
约 50%3/4 · 三档以内可互换≤ 50%明显变乱，前期可能捡到后期货
0%4/4 · 等级完全放开100%最疯，纯娱乐

滑杆下面会实时写清「档位：X/4（合理度 N%，跨度 n/4）」，不用自己算。

4.4 单池合理度（会跟着混合方式自动出现）

混合方式不同，「单池合理度」那几行会出现得不一样 —— 这是设计，不是 bug：

混合方式上面那条「总合理度」下面出现几条
全部混合可用，统管混池一条都不出现（三类都进了混池）
两两混可用，统管混池只有「落单那一类」一条
各自随机置灰（它不参与）卢恩 / 护甲 / 装备 各一条

没动过的那几条会跟着总合理度走；一旦你单独拖过某一条，它就不再跟随。法祷护甲永远没有单池合理度（它不分级，合理度对它没意义）。

4.6 种子：想复现就关掉自动换

  • 底栏的种子就是这整套结果的「随机数钥匙」；同一个种子 + 同一套设置 = 完全一样的结果。
  • 默认勾着「每次开始随机都换种子」；想对比两套设置、或者想重玩同一套，取消勾选、手动填种子即可。
  • 种子会一起存进方案；以后「载入到设置」还能把当时的参数填回来。

4.7 生成之后看什么

生成完跳回方案库之前，「结果」卡与「详细记录」会告诉你这次改了什么：

  • 这次会改什么：一句话总结（改了多少格、分类明细等）；
  • 详细记录 → 检查项：逐项自检（备份、复核、基线）是否通过；
  • 详细记录 → 前 300 条替换：原来是什么 / 换成了什么 / 在哪儿（这是抽样展示，不是全部）；
  • 详细记录 → 日志：完整过程，出问题时把这一段发出来最有用。

05敌人随机

把地图上摆着的敌人换成别的敌人。它有一套完整的「规则 → 来源 → 写入」管线，默认就很克制；想乱也有现成的预设。

5.1 它怎么工作：三条链路

① 位置（谁）

全游戏 27,780 条敌人摆放记录，先被分成 9 个可见类 + 6 个内部标记类。内部标记类（随从、复制体、粪金龟等）只用来标记「不能动」，不参与随机、不当来源、也不进界面。

② 规则（换成谁）

四类特殊规则先行（多阶段 BOSS / 传送门守门 / 有血条的 BOSS 位 / 劳弗圣龛），其余按逐类预设：每个目标类有自己的「换入来源百分比」。

③ 写入（怎么落地）

克隆 NpcParam 行 → 换地图实体的模型 / npc / AI / 外观四字段 → 改血条名 → 给克隆行挂一条区域强度 SpEffect。原 NpcParam 表一行不动。

默认计划（不选预设）的规模：25,656 个随机单元 → 22,509 个被替换 → 覆盖 24,459 个位置，跳过 3,147 个。选预设后数字会略有不同，界面预览会给你当前这套的准确数字。

5.2 四个特殊池（默认全开）

有些位置不是普通刷怪点，而是特殊玩法的一部分。它们被单独编成「池」，勾选框管三件事：池里的位置要不要随、池能不能当别人的来源、池内位置自己选什么来源。

池是什么默认关掉会怎样
黄金树传送门各地传送门旁的守门敌人（固定搭配，换错了位置会变得很怪）开守门位保持原样，别的随机不受影响

5.5 区域缩放与 BOSS 数值平衡

区域缩放（每个位置单独算）

换入的敌人按它所在区域的强度档重新算血量 / 攻击 / 防御 / 抗性 / 魂：每个位置一条独立 SpEffect，挂在克隆行上，原始表一行不改。所以把盖利德的 BOSS 换到宁姆格福，它会变弱；反过来变强。

BOSS 换进杂兵位还要再压一档（血 ×0.25 / 魂 ×0.25 / 攻击 ×0.5），否则就成了「血量像杂兵、打人还是 BOSS」。

BOSS 数值平衡（默认自动带）

BOSS→BOSS 的位置，血量按这个位置原来那只 BOSS 的强度对齐（不是按换入者自己的原版血量）：分位分层抽（k=10）+ 硬夹在 0.85–1.25 倍。

前期区域不会出现「后期 BOSS 的巨血」，后期也不会换进来一个一刀就死的纸糊 BOSS；杂兵位不动，写盘仍是克隆行 + 区域 SpEffect。

v1.4.1 修过一个双重缩放：以前「普通位置换成 BOSS」会被扣两次血（写盘 ×0.25 之后，平衡层又按写盘前的值锚一次），实际只剩位置原血量的约 0.25。现在有效血量回到位置原强度 ±25%（01 预设那 29 个位置实测 p50 ≈ 0.98×）。如果你还在用旧版，换成当前版本就好。

三个开关的差别：区域缩放是自动的、永远生效；BOSS 平衡默认自动带（高级用法在计划里关 features.balance）；生命值倍率是叠加在这两者之上的整体微调。

07开玩与独立存档

7.1 开玩流程

  1. 双击方案：如果覆盖层还没生成，先在后台生成（只物品约几十秒；含敌人约 3 分钟）。
  2. 换档：把这个方案自己的存档换进游戏（第一次会问「这个方案还没有存档，现在就用新角色启动吗？」）。
  3. 挂载：把方案层写进 yafsml\YAFSML.ini 的 Plan=。
  4. 起游戏：进游戏就是这一套世界。
  5. 退出游戏：进度自动存回这个方案自己的槽（界面开着时每几秒看一次进程；界面关着退出，下次打开 1.5 秒后补存）。
  • 游戏正在运行时点也可以：会先问「自动关掉它并启动吗」—— 先请它自己退，实在不退才强杀；强杀会丢最近一小段进度。
  • 任务管理器里有个 eldenring.exe 却看不到窗口？那是退出后没被系统回收的「空壳」（线程/句柄 0），新版会跳过它，不用手动杀（也杀不掉，系统会自己收掉）。
  • 生成 / 换档期间按钮会置灰并显示进度；卡住就看方案库底部那行小字，它会写卡在哪一步。

7.2 每个方案一份独立存档

  • 存档放在 法魂包\存档库\<方案名>\（和 方案\ 并排；删游戏本体、换机器都不会丢）。
  • 任何覆盖 / 删除之前都会先留底到 存档库\_回收\。
  • 第一次用某方案会问「现在就用新角色启动吗？」：选「否」= 什么都不动；选「是」= 旧档先归到「上一个方案」或 _法魂本体 槽，再开新角色。
  • 从层目录双击 「用这个方案启动.bat」 也算这条路（换档 → 挂载 → 起游戏 → 退出回存），日志在层目录的 启动日志.txt；「切回法魂本体.bat」 = 删掉挂载。
  • 文件名跟着法魂包的 YAFSML.ini 走（常见 ER0000.cnv；没配改名时是 ER0000.sl2），工具会按配置读写，不用你管。
玩多套方案前，先把 Elden Ring 的 Steam 云存档关掉。云同步可能在另一次启动把档换回去，这个工具管不着 Steam。另外：只能单人离线，不能联机。

11常见问题

点了「用这个方案玩」，一点动静都没有？

先看方案库底部那行小字，它会写卡在哪一步。两种最常见的情况：

  • 覆盖层还没生成：点一下就在后台生成（含敌人约 3 分钟）；期间按钮变成「正在生成覆盖层…」并置灰，完成后会自动接着开局。
  • 游戏还开着：会问你「自动关掉它并启动吗」。同意就替你关掉再开（先请它自己退，实在不退才强杀）。两个都点「否」= 什么都不动。
提示「关不掉还在跑的游戏」，可任务管理器里又看不到游戏窗口？

v1.3.9 起已修。游戏退出后任务管理器会留下一个 eldenring.exe 的「空壳」（线程 / 句柄都是 0、内存几十 KB，手动结束还会提示拒绝访问）。旧版把它当成游戏在跑，于是每次都先问、等 35 秒后报错。新版会跳过这种空壳；不用手动杀（也杀不掉，系统会自己收掉）。

「编辑逐类预设」里怎么只剩 9 个类别了？法魂杂兵去哪了？

v1.3.12 起调整：法魂杂兵并进「常规敌人」（同一档强度，池子更大）。另外 6 个分类（未分类 / 随从召唤物 / 复制体 / 假人测试体 / 粪金龟 / 商队巨魔）不再显示、不再随机、也不当来源 —— 原因见「哪些默认不碰」一节。

我自己改过的逐类预设要重做吗？

不用。v1.3.12 起载入时自动迁移：旧「法魂杂兵」的百分比并进常规敌人，被删掉的类别条目自动丢掉；保存一次就变成新格式。

进游戏以后，每隔两三秒屏幕闪一个黑色终端框？

v1.3.10 起已修。旧版在等游戏退出时每 2 秒起一次 tasklist，窗口版 exe 没控制台，于是每查一次就新建一个黑框。新版改成直接读系统进程快照，不再弹框。

换了方案，进游戏看到的还是原来那个角色 / 进度？

v1.3.10 起已修。法魂包的 YAFSML.ini 配了 replace_save_filename=.cnv，游戏读写的是 ER0000.cnv，而旧版只认 ER0000.sl2 —— 换档换了个游戏不读的文件。新版会从 YAFSML.ini 现读档名；老存档槽第一次运行会自动改名（内容不动，原文件在 存档库\_回收\ 留一份），不用你手动做什么。另外「切回法魂本体」现在也会真的把本体档换回来。

双击层目录里的「用这个方案启动.bat」，提示「法魂包根目录不对（没有 yafsml\）」？

v1.3.8 起已修（层里也有一份 mod\regulation.bin，从层目录启动时被误当成法魂包本体）。如果还在用旧版：最省事是别从层目录启动，回随机器打开方案库双击那一行。

把整个文件夹搬到别的盘、改个名、换台电脑，还能用吗？

可以。工具按「目录里有 mod\regulation.bin」找法魂包，不看文件夹名（从它所在目录往上最多 7 层，连同级目录一起看）。搬完第一次打开若「环境」有红项：点「指定 MOD 目录…」重选一次，或设环境变量 CONVERGENCE_MOD_ROOT。旧方案不用重做：覆盖层按目录名找回，找不到会在下次开玩时重新生成。

杀软提示 / 拦下载 / 点开没反应？

exe 未签名，杀软提示属正常，加信任即可。工具不联网、不改游戏本体。第一次运行会生成工作文件，稍等几秒；若一直不动，看 exe 旁边有没有 investigation 文件夹。

报错说找不到 oo2core*_win64.dll？

打开游戏安装目录里的 Game 文件夹，把 oo2core_*_win64.dll 复制到 exe 旁边的 oodle 文件夹（没有就新建）。放一次即可。

我的存档存在哪？换方案会不会把原来的档弄丢？

每个方案一份档，都在法魂包 存档库\<方案名>\；任何覆盖 / 删除之前都会先复制到 存档库\_回收\。第一次用某个方案玩会先问你；选「否」= 什么都不动。文件名跟着 YAFSML.ini 走，工具按配置读写，老版本存的 .sl2 槽第一次运行会自动改名。

用方案库启动，Steam 那边会不会打架？

会。玩多套方案前先关掉 Elden Ring 的 Steam 云存档，否则云同步可能在另一次启动把档换回去。

能联机吗？关掉工具还能改回来吗？

不能联机，单人游戏专用；用之前请先备份存档。能改回来：点「还原成原始」（原始备份一直在 exe 旁边的 investigation\apply\backup 里）。

开始随机后报「写前复核未通过（…条与当前文件不一致）」？

说明工具手里的「原始备份」不是真正的原版 —— 最常见原因：第一次补备份时本体已经被随机过（以前直接写过本体），于是把改过的文件当成了「原始」。处理：把法魂 mod 原版的 regulation.bin 放回本体（重装或用你留的原版文件）→ 再点「补一份原始备份」。跟种子无关，换什么种子都会一样报。

换进去的敌人 T-pose / 悬空 / 卡住 / 战斗不结束？

敌人随机不是 100% 无风险：特殊位置（A 批事件系 BOSS、B 批双人第二只、实验开关）可能出现动作或演出问题。处理顺序：

  • 先换回 01 参考默认·同族池、四个池全开、其它开关默认，重建一套方案对照；
  • 若确认是某个开关（颜色 / 双人第二只 / 忽略体型 / 敌人倍增）造成，关掉它重建；
  • A 批某个位置坏了：在 enemy_classes_v3.yaml 的 overrides.places 里删掉那一行重建数据；B 批：把对应组设 enabled: false 或取消开关；
  • 实在不行就「切回法魂本体」，本体永远干净。
为什么二阶段 BOSS（比如梅瑟莫）被换到别处后只会一阶段招式？

因为「阶段切换」是原战场 EMEVD 事件驱动的：血量到一半后禁用一阶段实体、启用二阶段实体、加 SpEffect、播动画。以前克隆到别的战场只带得走模型和名字，带不走这套事件。现在分两层处理：v1.4.2 起二阶段身份不再单独当来源（避免「挂着二阶段名字只有一阶段招式」）；v1.5.0 起对「本来只有一只 BOSS」的目标位置会把变身事件一起搬过去（克隆二阶段实体 + 写变身 / 隐藏 / 死亡桥接三个事件，默认开）；v1.5.1 修掉了 v1.5.0 的「进图崩 / 进游戏 50 秒崩 / 变身不触发」三个问题。目标自己就是多阶段场地、或来源没有配方（米德拉 / 幽影树化身等）时不搬，那里仍然只有一阶段——想体验它们真正的二阶段，请保留原战场、关掉对应位置的多阶段替换。

为什么「普通位置换成 BOSS」不会突然变得超模？

区域缩放会按位置所在区域的强度档重算换入者的血 / 攻 / 防 / 抗 / 魂，每位置一条独立 SpEffect 挂在克隆行上；BOSS 进杂兵位还有额外降级（血 ×0.25 / 魂 ×0.25 / 攻 ×0.5）。v1.4.1 修掉了「平衡层又扣一次」的双重缩放，现在有效血量回到位置原强度 ±25%。

「开始随机」要多久？会占很多空间吗？

生成方案本身几秒到几十秒（纯计算，不写盘）。真正花时间的是第一次开玩生成覆盖层：只物品约几十秒；含敌人约 3 分钟；物品 + 敌人约 3–4 分钟。每套方案的覆盖层是独立的，会占磁盘（含地图和事件，几百 MB 级）；不玩的方案可以在 方案\ 里手动删层，不影响本体与方案库。
