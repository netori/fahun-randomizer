# 便携性（绝对路径审计与修复）· 2026-10-23

> 一句话：**把工具和法魂整合包一起搬到别的盘、改个文件夹名、换一台电脑，也一样能用。**
> 本次只动「怎么找路径」，随机算法、写盘格式、界面流程都没改。

---

## 一、为什么会有这件事

以前的路径是从「这台机器、这个盘符、这个文件夹名」推出来的 —— 典型写法是

    F:\game\studygame\elden ring\THE_COVERAGE-随机开发\法魂mod V3.0.3 汉化本体（适配游戏版本1.17.1）（新YAFSML引擎V0.10.4）

这类写法放在自己机器上没问题，但一旦：

- 把整合包从 F: 挪到 D:；
- 把整合包文件夹改个名（版本号一升级就会变）；
- 只把 exe 拷给朋友（他那边没有你的目录结构）；
- 方案库里的方案是**旧路径**下生成的，搬完目录就找不到自己那层了 ——

就会报「找不到」、或者悄悄用了别的东西。方案库的 `layer_dir` 就是典型：它把生成当时的**绝对路径**存进了方案 json。

## 二、新的路径规则（唯一入口：`investigation/apply/modpaths.py`）

### 2.1 怎么认法魂包

**判据不是名字，是内容**：目录里有 `mod\regulation.bin` 才算法魂包的 mod 目录；再往上一级有 `yafsml\` 就能当包根（方案层要靠它挂载）。

查找顺序：

1. 环境变量 `CONVERGENCE_MOD_ROOT`（显式指定，最高优先级）；
2. 从「当前文件 / exe 所在目录」往上最多 7 层，每一层看它自己和最多 400 个同级目录；
3. 多个候选时打分：名字里带「法魂」/ `convergence` 的优先，其次 `regulation.bin` 修改时间更新的。

找不到时**不会静默失败**，而是抛一段人话：

    没找到法魂 MOD 目录（判据：目录里有 mod\regulation.bin）。怎么办（任选一条）：
    ① 把随机器 / exe 放到法魂整合包旁边（同一层目录）；
    ② 界面「本地文件」点「指定 MOD 目录…」；
    ③ 设环境变量 CONVERGENCE_MOD_ROOT=…

### 2.2 游戏目录

认 `eldenring.exe`（`<目录>\eldenring.exe` 或 `<目录>\Game\eldenring.exe` 都行），归一成 `Game` 目录。查找顺序：`CONVERGENCE_GAME_DIR` → `ER_GAME_DIR` → 从法魂包/工具目录往上找。

### 2.3 可用的环境变量

| 变量 | 作用 |
|---|---|
| `CONVERGENCE_MOD_ROOT` | 法魂包的 **mod 目录**（里面有 `regulation.bin`） |
| `CONVERGENCE_GAME_DIR` | 法魂游戏目录（`ELDEN RING\Game`） |
| `ER_GAME_DIR` | 同上（旧名字，仍认） |
| `ENEMY_REF_DIR` | 开发期参考实现（Randomizer 的 `diste` 目录），打包版不需要 |
| `VANILLA_REG` | 开发期原版 `regulation.bin`，打包版不需要 |

### 2.4 方案库里的「层」不再信旧路径

方案 json 里的 `layer_dir` 是生成当时的绝对路径，搬家后会失效。现在解析顺序是：

1. 方案里记的 `built.label`（覆盖层目录名）→ 去**当前**方案目录下找同名层，存在 `mod\` 就用它；
2. `layer_dir` 原样，存在 `mod\` 就用；
3. `layer_dir` 的目录名（basename）回当前方案目录里找；
4. 都找不到 → 返回空（下一次开玩会重新生成，不报错）。

另外，**每次点「用这个方案玩」都会重写层里那两个 bat**（`用这个方案启动.bat` / `切回法魂本体.bat`）—— 层被拷到别的电脑后，bat 里旧的 exe 路径会被换成当前这台机器上的。

## 六、边界（有意为之）

- **存档目录**仍按系统来（`%APPDATA%\EldenRing\<SteamID>\`）—— 这是游戏自己认的位置，不能搬。
- **方案库**在 exe 旁边（`<工作区>\plans\`）。只把 exe 单独拷走，方案不会跟着走；把整个工具目录一起拷就都在。
- **存档库**在法魂包下（`<法魂包>\存档库\`），跟着整合包走 —— 换机器时整合包一起拷，存档也一起过去。
- 游戏里那些 `N:\GR\...`、`sib` 路径是游戏自己的资源索引，不是「本机路径」，不受影响。
