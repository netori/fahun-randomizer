> 状态：**只是讨论稿，没有动代码**。

## 0. 一句话

参考实现（thefifthmatt）之所以能「全物品随机」，靠的不是算法，而是**几万人力的地点/物品/区域逻辑标注**；
我们抄不了那套数据，但**能抄它的形状**：显式「重要地点」+ 物品分组 + 三态开关 + 不变量表。
以我们现有的写盘能力，第一步就能做到「世界拾取 + 敌人掉落 + 商店」全量随机，
真正的取舍只有三个：**关键道具要不要动、池子切多细、数量与价格怎么守恒**。

## 1. 现在做到哪一步（现状）

现在的物品随机（v1）是一个**说明书驱动**的随机器：

| 项 | 现状 |
|---|---|
| 范围 | 只处理「职业说明书物品集合 G」：682 件（护甲 518 / goods 162 / 武器 2） |
| 落点 | 这些物品在 **ItemLotParam_map / ItemLotParam_enemy** 里的格子：766 格（地图 742 + 掉落 24） |
| 商店 | 只在「商店卖 G 里那几件」时 +9 格 |
| 规则 | 取值范围 = G；按流派/部位/档位分池；护甲整套不拆；法祷与近战隔离；守恒；可复现 |
| 写盘 | 计划 CSV → native_apply 就地改 regulation.bin（格子数/概率/价格/flag 全不动） |
| 关键道具 | 不碰 |

**也就是说：世界上绝大多数物品现在都没被随机。** 一局游戏里 11,700 个物品格里，只有 766 格（6.5%）会变。

## 2. 参考实现到底做了什么（thefifthmatt v0.12.2）

> 详细拆解见调研笔记（本机参考包 README + EXE 字符串 + diste 数据；源码地址不可达）。

### 2.1 覆盖面：六个面，几乎全随机

- **世界拾取物**：总是随机（没有独立开关）
- **敌人 / Boss 掉落**：总是随机（只有「给掉落加保底副本」的开关）
- **商店货架**：总是随机（法术店可保留本法术）
- **初始职业装备 / 初始遗物**：可开关
- **关键道具**：默认随机，但只放「重要地点」；三态：重要地点 / 任意地点 / 不随机
- **地图碎片、血瓶、灵马笛、蛇矛**：默认不随机

### 2.2 数字规模（它的护城河）

| 资产 | 数量 |
|---|---|
| 地点槽 | 4,379 个槽 → 3,994 个聚合地点；3,200+ 个真正的地点 |
| 手写地点描述 | 2,015 条（其余自动生成） |
| 物品名 | 2,448 条（weapon 513 / protector 637 / accessory 154 / goods 1,039 / gem 105） |
| 语义物品组 | 29 组（keyitems / greatrunes / questitems / legendary / rare / 锻造石 / 骨灰 / 法术 / 祷告…） |
| 区域逻辑图 | 362 个区域（361 条布尔可达表达式）+ 46 个事件 + 100 条放置限制 |
| 默认预设 | 10 条放置规则 + 2 组高级商店规则（YAML） |
| 要改写的游戏文件 | 1,682 个（map 1,071 / event 546 / msg 28 / script 36 / sfx 1） |
| 选项 | 物品相关 43 个（Item 页 17 / Logic 页 18 / Misc 页 8） |

### 2.3 它绕不开、我们绕得开的东西

- 它必须改 **1,071 张地图 + 546 个事件**：因为它要把物品放到「新地点」、要改地图上的拾取实体、要改事件给的物品。
- **我们只写 regulation.bin 的 ItemLotParam / ShopLineupParam 就够了**：物品格子的「放什么」就在这两张表里；
  地图/事件不需要动（现有写盘链已经完整验证过，物品侧连地图都不用碰）。
  ⇒ 这是我们的巨大优势：方案层、独立存档、开玩时才建层，这套流程完全不用改。

## 4. 关键技术判断

1. **只写 regulation 就够**：世界拾取的物品定义在 ItemLotParam_map，掉落定义在 ItemLotParam_enemy，商店在 ShopLineupParam；
   写这三张表不需要改地图/事件/msg。**现有 native_apply / 写前复核 / 方案层 / 独立存档全部沿用。**
2. **数量语义**：goods 的 num 是堆叠数（1/2/3/5/10/99…）；装备的 num 都是 1。同类互换时保留 num；
   若允许跨类混池（材料格子里出武器），num 必须压到 1（否则一次捡 5 把同名武器）。
3. **关键道具能随机，但「能不能通关」不归我们管**：参考实现靠 362 个区域布尔表达式保证「钥匙不会锁在自己后面」。
   Convergence 改过地图与主线结构，这套逻辑我们**没有**，重做成本极高（数据量在标注不在代码）。
   ⇒ 默认：**关键道具 / 大卢恩 / 追忆 一律不随机**（390 格，保持原位）。这是最稳的 90 分方案。
4. **有效物品池只有「真的出现在格子里的物品」**：goods 1,614 个 id、武器 750、护甲 844、战灰 119、护符 5。
   这比 EquipParam 全表小得多（goods 表 3,792 行，武器表 4,874 行含强化等级），天然就是「可获得物品」白名单。
5. **法魂的自造内容**：类别 6 = EquipParamCustomWeapon（1,671 行），格子里有 11 处；随机时要么单独成池，要么跳过。
6. **名字缺口**只影响界面/日志的可读性，不影响写盘正确性（写的是 id+category）。

## 5. 三个方案

### 方案甲：全物品大混池（最像参考实现）

- 所有可随机物品进一个大池，任何格子都可能变成任何物品（保留关键道具冻结）
- 优点：最接近参考手感，「探索未知」最强
- 缺点：法魂的前期平衡会被打散（新手村出终局武器/大量废品）；材料经济崩溃；goods 堆叠与装备混放要特殊处理
- 工程量：中（池子最简单，但要处理跨类数量/价格）

### 方案乙：分层同类 + 可选混池（推荐）

- 池子先按类别切：
  - 武器 ↔ 武器（可选再按 weaponCategory 细分为 12+ 类）
  - 护甲 ↔ 同部位护甲
  - 护符 ↔ 护符、战灰 ↔ 战灰
  - goods 按类型组：消耗品 / 素材 / 强化素材 / 黄金卢恩 / 法术 / 祷告 / 骨灰 / 书信 / 露滴
  - 强化素材与卢恩：**保持原档**（锻造石仍按等级、卢恩仍按面值），保证成长曲线
- 再给一个「混池比例」滑块（0–100%）：按比例把物品放进跨类混池（类似现有合理度）
- 商店：同类别 + 同价格档内换（价格不动）
- 优点：默认手感稳、风险可控、可逐步放开；复用现有「合理度/混池」交互
- 缺点：默认下的惊喜感不如甲

### 方案丙：最小可用

- 只随机世界拾取里的 goods（材料/消耗品/卢恩）与商店；武器/护甲/掉落不动
- 优点：最快（1 个会话内可出东西）
- 缺点：没什么意思，「其他物品随机」的爽点全在装备上

## 6. 推荐路线（方案乙，分三期）

### P1：世界 + 掉落，同类池（先跑通）

1. 新模块 investigation/apply/item_world.py：从 regulation 读三张表 → 建格子 → 按类别/类型分组 → 池内置换 → 出计划 CSV（含 num 列）
2. 跳过：认不出的 id（487 格）、关键道具/大卢恩/追忆（390 格）、固定格子
3. native_apply 扩展：允许写 lotItemNum（装备压 1）
4. GUI：物品页新增「随机范围」卡：世界拾取 / 敌人掉落（勾选）、预览统计（每类多少格、示例）、种子
5. 自检 + 离线写盘 + 进游戏抽查（拾取几个点、打一个 Boss 看掉落）

### P2：商店 + 数量/价格

1. 商店按类别 + 价格档池内换（价格/库存/解锁不动）
2. 数量语义收尾（堆叠 vs 装备）
3. 混池比例滑块 + 预览

### P3：向参考实现靠拢的体验项（可选）

1. 显式「重要地点」计数（Boss 掉落 / 商店 / 金种子树…）
2. 关键道具三态（要先有 Convergence 的可达性判断，风险自担）
3. 名字抽取（Data0 zhocn 的 Weapon/Accessory/GemName）+ spoiler log
4. 铃珠与商店一致性

**估算**：P1 约 2–3 个会话；P2 约 1 个；P3 每项 0.5–1 天起。

## 7. 需要你拍板的 6 个问题

1. **关键道具**：默认「不随机、保持原位」可以吗？（要随机就得接受「可能卡关」或以后补逻辑）
2. **混池程度**：默认「同类互换」，额外给一个混池滑块 —— 还是直接上方案甲的全混池？
3. **商店**：同类别 + 同价格档内换（价格不动）可以吗？还是想按物品价值重算价格？
4. **职业物品随机**：并入新的「物品随机（范围可选：职业物品 / 其他物品 / 全部）」？
   （推荐合并；旧配置自动映射成「职业物品」，不影响老方案）
5. **名字**：先只显示「类别 + 格数」，还是我去抽游戏里的中文名表（约 1 天）？
6. **强化素材/卢恩**：保持原档（锻造石不越级、卢恩面值不变）默认开，可以吗？
