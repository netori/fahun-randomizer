# 方案层使用说明（法魂随机 · YAFSML 覆盖层）

> 一句话：**每次随机都会顺手做成一个"覆盖层"**，双击层里的 `用这个方案启动.bat` 就用它玩；
> 想切回纯法魂，双击 `切回法魂本体.bat`。**法魂本体（`法魂包\mod\`）从此永不被改。**

---

## 1. 它是怎么生效的

法魂包用的是 **YAFSML** 加载器（`yafsml\YAFSML.ini`）。它的 `[mod]` 段原文写着：

> 扫描并覆盖游戏数据的模组目录；**后声明的模组覆盖先声明的模组中的同名文件**。

所以只要在 `[mod]` 段里、`Convergence=../mod`（本体那行）**之后**加一行：

```ini
[mod]
Convergence=../mod
Plan=../方案/20261016_1430_种子12345_物品+敌人+说明书
```

游戏就变成"法魂本体 + 这个方案的差异" —— 本体那行一个字不动。

`用这个方案启动.bat` 就是替你写这一行、然后调用 `启动法魂.bat` 启动游戏。
`切回法魂本体.bat` 就是把这一行删掉。

两个脚本都只改 `[mod]` 这一段，改前会把 `YAFSML.ini` 备份成 `YAFSML.ini.bak_planlayer_<时间戳>`；
写回时保持**编码 / BOM / 行尾**与原文件一致（实测：挂载只多一行、卸载后**逐字节**复原）。

---

## 2. 一个方案层里有什么

```
法魂包\方案\<标签>\
  mod\regulation.bin                        2.9 MB —— 部署完的那份（物品 + 敌人一起）
  mod\map\MapStudio\<改过的>.msb.dcx         只有"真换敌人"时才放（每张 ~0.4 MB）
  mod\msg\zhocn\item_dlc02.msgbnd.dcx        只有同步了说明书、且与原始不同时才放（省 16 MB）
  用这个方案启动.bat / 切回法魂本体.bat / 方案信息.txt
```

标的体积就这样：**每方案 ~3 MB**（地图多的方案再 +几 MB）。100 个方案也就几百 MB。

---

## 3. 日常怎么用

```bat
:: 正常生成 + 写入（GUI 里做）—— 写完会自动生成方案层，日志里会打印目录
:: 想用某个方案玩：
双击  法魂包\方案\<标签>\用这个方案启动.bat
:: 想切回本体：
双击  法魂包\方案\<标签>\切回法魂本体.bat
```

命令行也行：

```bat
cd 随机mod\investigation\apply
python plan_layer.py                    :: 看现在挂着哪个方案、有哪些方案
python plan_layer.py --activate "法魂包\方案\<标签>"
python plan_layer.py --deactivate
python plan_layer.py --export --label 我的方案名     :: 手动把当前状态导出成一个层
```

## 4. 几条要记住的规则

1. **后声明覆盖先声明** ⇒ 同时只能挂一个方案；两个方案都改同一张地图时，后挂的那个赢。
   → 所以别指望"多个方案叠加"，正确做法是**一次部署就把物品+敌人一起出**（我们的部署本来就是这么做的）。
2. **法魂本体永不动** ⇒ 想彻底回原版：`--deactivate`，或者干脆直接双击 `Game\eldenring.exe`（绕过加载器 = 纯原版）。
3. **存档兼容** ⇒ 我们只改参数的**内容**、不改行 id，所以存档引用的东西还在 ⇒ 切方案不必换档。
   （YAFSML 侧 `replace_save_filename=.cnv` 是全局的，法魂存档与纯原版天然分开。）
4. **`regulation.bin` 每方案一份**是必要代价（它是一个整体文件，没法只覆盖其中几张表）；
   好在它只有 2.9 MB。
5. **备份**：`yafsml\YAFSML.ini.bak_planlayer_*` 是我们的；你自己 10-10 那次改动的备份是 `YAFSML.ini.bak_20261010_205216`，别混。

## 5. 实现位置（给以后维护用）

| 文件 | 干什么 |
|---|---|
| `investigation/apply/plan_layer.py` | 产出层 / 挂载 / 卸载 / 列表；`_read_text` 记 BOM 与行尾，`write_ini` 原样写回 |
| `investigation/apply/native_deploy.py` | 部署最后一步（⑦）调用它；层里放的是**部署完**的 regulation，所以必须在所有写入之后 |
| `randgui.py` | 部署时给标签（时间_种子_物品/敌人/说明书）与元信息（种子、比例、来源、指纹） |
