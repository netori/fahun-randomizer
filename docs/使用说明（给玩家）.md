# 法魂职业道具和装备随机器 · 使用说明

> 面向玩家。全程在本地运行，不联网。
> 作用一句话：**道具与敌人都能打乱重排** —— 物品名不动、只换它现在所在的地点；
> 敌人则按你选的规则换成另一个敌人，并按所在区域把强度调回去（换进来的 Boss 会被压到杂兵量级）。
>
> 三个页签：**职业物品随机** / **敌人随机** / **方案库**（存方案、一键开局）。

---

## 一、用之前要有什么

| 需要 | 说明 |
|---|---|
| **ELDEN RING** | 版本与你那份法魂本体一致（本版针对 1.17.1） |
| **「法魂」汉化本体 V3.0.3** | 本工具改的就是这份 MOD 的数据文件，**不能单独使用** |
| **你自己那份原版文件** | 就是你刚装好法魂时的那两个文件；工具会在**首次写入前自动备份**它们 |

⚠️ **本工具只支持中文版（法魂汉化本体）** ✗ —— 英文版或其它语言版**不适用** ✓。

---

## 二、安装（一步）

把 **`ConvergenceClassItemRandomizer.exe`** 放到 **MOD 根目录** ✓：
就是**含 `mod\regulation.bin` 的那一层** ✓（和 `mod` 文件夹、`启动法魂.bat` 并排）。

> 跟存档目录没关系 ✓；不需要 mod 管理器 ✓；不需要安装 ✓。

## 四、三个选项怎么选

### 1）随机项目
勾你想动的：**卢恩** ✓ / **护甲** ✓ / **装备（武器）** ✓ —— 至少勾一项 ✓。

### 2）混合方式（勾多项时才需要想）
| 选项 | 意思 |
|---|---|
| **全部混合（勾选的几类一起混）** | 卢恩、护甲、武器**一起混** —— 变化最大 |
| **两两混 · 剩下独自**（三种） | 勾满三项时才会出现：比如"卢恩+护甲混，装备独自" |
| **各自随机（勾选的几类各随各的）** | 三类**各随各的**，互不掺和 —— 最保守 |

> 法师/祷告护甲**始终单独一组** ✓，无论选哪个都不会跟近战混 ✓。

### 3）合理度（0~100%）
一个滑块 ✓，但它同时控制三件事 ✓（界面下方那行绿字会实时告诉你是多少 ✓）：

- **越档幅度** —— 最远能跨几档（100% 只能同档互换 ✓，0% 完全放开 ✓）
- **越档率** —— 多少东西真的跨档（100% 时是 0% ✓）
- **武器掺入上限** —— 武器混进混池的比例（上限 66% ✓）

> **推荐**：第一次玩**先从 80% 开始** ✓（相邻两档可换 ✓、跨度 2/4 ✓、越档率 ≤20% ✓）
> —— 既有新鲜感，又不会出现"新手村捡到毕业装" ✓。

#### 3b）单池合理度（跟着混合方式自动出现）
> 就在**同一个「第 2 步 · 合理度」**里 ✓ —— 没有额外开关，该出现的自己会出现 ✓
> **没有勾选框**：行一出现滑块就在生效 ✓；**没动过的那些跟着总合理度走**（那行末尾会写「跟着总合理度」）✓

规则就三句，跟着「混合方式」和"勾了哪些随机项目"走：
- **有混池时**：上面那条**总合理度管混池** ✓，下面只摆"自己还成池"的那些类别 ✓。
- **全部混合**（三个类别都进了混池）：下面**一条都不摆** ✓ —— 只有总合理度 ✓。
- **各自随机**（没有混池）：**总合理度变灰**（那会儿它不参与）✓，**卢恩 / 护甲 / 装备**三条各管自己那一类 ✓。
- **两两混**：总合理度管那个混池 ✓，只有**落单那一类**有自己的那条 ✓。
- 没勾的随机项目不出现 ✓；**法祷护甲永远没有这一条** ✓（它不分等级，只在法祷内部互换）✓。

**每行都写着"这条现在会造成什么"** ✓（拖的时候实时变）：
> `相邻两档可互换　跨度 2/4　越档率 ≤20%` —— 跨度越大越容易跨档，越档率就是"能跨档的比例上限" ✓。

### 4）改动比例（只有法祷那一条）
> 在「更多设置」里 ✓ —— **没有勾选框**：行出现时滑块就在生效，**没动过＝这一类全改（100%）** ✓

- **法祷职业护甲** —— **整套与散件一起**按这个比例改 ✓
  （例如 40% ≈ 四成法祷护甲参与互换；"这次会改什么"里会给出换了几套、几件 ✓）。
  末尾实时写着效果：`全改（100%）` / `≈40% 的整套 / 散件参与互换` ✓；关掉「整套一起换」时标签变
  「法祷职业护甲（**散件**）」✓。
- **商店没有比例条**（2026-10-14 定）：勾上「商店里的职业装备也一起换」＝**在卖的职业装备全部参与** ✓
  （不做二次抽比例 ⇒ 不用担心"商店改太少"✓）。
- 取消「护甲」→ 法祷那条收起来 ✓。

> **它到底怎么生效的**（抽子集，由种子决定，所以同种子可复现）：
> 在**每类池子里**抽 `round(池大小 × 比例)` 个单元，只在这个子集**内部**互换，没抽中的原样 ✓。
>
> **商店参与范围**（为什么商店看起来只有一部分变了）：本工具只管**说明书里那批职业装备**，
> 商店里在卖的职业装备共 **69 行（法祷护甲 50 件 / 近战护甲 16 件 / 武器 2 件）** ——
> 这些**全部**参与、全部会变 ✓。剩下 1485 行不是职业装备（904 行卖的装备不在说明书里、
> 425 行价格 0/-1 并非在售、143 行是消耗品/骨灰之类、13 行是职业初始装备表），按设计不动 ✓。
>
> 商店卖的东西**没有自己的池子** ✓：抽中的那件与**同类别的全部物品**在同一个池里换，
> 所以货架上出现一件原本只在 boss 身上掉的东西是正常的（反过来，货架原来卖的那件会去宝箱/掉落）✓。
> 抽中的物品在**货架与宝箱/掉落里一起换**（不会出现"货架换了、宝箱还是原来那件"）✓。

### 5）法祷护甲整套一起换
> 在「更多设置」里 ✓

法师/祷告护甲**本来就不跟近战混** ✓；这一项决定它**内部**怎么换 ✓：
勾上 = **整套一起换** ✓（你拿到就是一整套 ✓）；不勾 = 按部位各自换 ✓。

> 法祷是个**大池子**：法师套 / 祷告套 / 混合套 / 感应套彼此互换 ——
> 所以可能在某处开出**别的法系**套装（比如原来放法师套的地方变成祷告套）。
> 这正是"法祷内部自由"的意思；要拦的只是"法祷 ↔ 近战" ✓。

### 6）种子
默认 **每次开始随机都会换一个新种子** ✓ —— 点一下就是一套新世界 ✓（种子显示在状态栏和方案里 ✓）。
想复现某一套：取消 **「每次开始随机都换种子」** → 把那个种子填回去 ✓ —— 同种子 = 完全一样的结果 ✓，
也能发给朋友复现同一套世界 ✓。

## 五、正式使用（三步）

1. 点底部的 **「开始随机物品」** ✓ —— 生成一套方案，**自动存进方案库** ✓。
   只想要物品就只勾「职业物品随机」；把「敌人随机」的勾也留着，按钮会变成 **「开始随机物品和敌人」** ✓。
   结果会留在「**这次会改什么**」里 ✓；种子没变的话再点一次是**同一套结果** ✓。
   **这一步不写任何游戏文件** ✓ —— 不会碰法魂本体，也不会挂载什么东西 ✓。
2. 打开 **📚 方案库** ✓，**双击刚生成的那一行**（或选中它点「用这个方案玩」）✓。
   第一次开玩它会先**生成覆盖层**（物品 / 说明书 / 敌人 / 地图全叠在层里，法魂本体一个字节不改）✓，
   然后换档 → 挂载 → 起游戏 ✓；之后再玩这一套就直接开局（层已是最新）✓。
3. 进游戏 ✓，翻开任意职业的**说明书** ✓ —— 看到的物品名和原来一样 ✓，**地点全变了** ✓。

## 五点五、方案库（每次随机的方案都在这里，双击就玩）

界面顶上有三个页签 ✓：**职业物品随机**（物品的生成 / 写入）· **敌人随机**（敌人的生成 / 写入）· **📚 方案库**（管方案）✓。
方案存在 **MOD 目录下的 `plans` 文件夹**里 ✓ —— 不放进 exe ✓，**重装工具也不会丢** ✓。

方案库是**左边列表 + 右边详情** ✓：点左边一行 ✓，右边就是它的全部信息 ✓，
**名字 / 备注 / 标签点一下就能直接改** ✓（不用再点按钮、也不会弹框问你 ✓）。

右边详情分成三段 ✓（2026-10-14 加细）：
- **随机设置** —— 随机项目（勾了哪些）· 混合方式（全部混合 / 两两混哪两组 / 各自随机）· 种子 ·
  合理度（单独设过的会写出来）· 改动比例 · 开关（整套法祷一起换 / 说明书跟着改 / 商店参与）✓
- **这次改了什么** —— 改动行（含跨大类多少行）· **分类明细**（护甲 X，其中法祷整套几套 / 散件几件 ·
  卢恩 Y · 装备 Z）· 商店换了几个货架 · 池子有几个（按类分布）✓
- **记录** —— 引擎版本 · 指纹 · 保存时间 · 修改时间 · **覆盖层**（还没生成 / 已生成的时间 / 设置改过的话下次开玩会重新生成）✓

| 想做什么 | 怎么做 |
|---|---|
| **把当前这套存下来** | 不用手动存 ✓ —— 每次点「开始随机…」生成的方案**自动**出现在这里 ✓；名字在右边直接改 ✓ |
| **用这一套开局** | **双击那一行** = 用这个方案玩 ✓（也可以选中它点「用这个方案玩」✓）—— 第一次会先按需生成**覆盖层**（几十秒到 3 分钟左右，看有没有敌人）✓ 然后换档 → 挂载 → 起游戏 ✓ 退出游戏后进度自动存回这个方案自己的槽 ✓（见下）|
| **在同一套上再改** | 「载入到设置」✓ 参数填回「随机设置」页 ✓ 改完点「开始随机…」会存成**新的一条** ✓ 旧的还在 ✓ |
| **改名字 / 备注** | 右边面板里点一下直接改 ✓ 回车或点走就存 ✓ |
| **改标签** | 右边「+ 添加」→ 回车 ✓；点标签上的 ✕ 就去掉 ✓ |
| **收藏** | 「收藏 ★」✓ 收藏的会排在**最前面** ✓ |
| **复制一套再改** | 「复制一份」✓ |
| **删掉** | 「删除」✓ —— 会先移进 `plans\.trash` ✓ 底部会告诉你「已移到回收站」并给你一个**打开回收站**的入口 ✓ |
| **给朋友 / 备份** | 「导出…」成一个 `.json` ✓ 对方用「导入」即可 ✓ |
| **方案多了** | 上面搜索框按**名字 / 标签 / 备注**筛 ✓；右边还能按 时间 / 名字 / 改动量 排序 ✓ |

其余动作（改名 / 收藏 / 复制 / 删除 / 导出 / 导入 / 打开文件夹 / 刷新）在**列表上点右键**就有 ✓。

⚠️ 列表里若出现带 ⚠ 的条目 ✓ 说明那个文件损坏了 ✓ —— **其余方案照常可用** ✓ 不会因为一个坏文件整库打不开 ✓。

### 每个方案一份自己的存档（2026-10-23）

以前所有方案**共用一份存档** ✓ —— 在方案 A 玩到 60 级，切到方案 B，B 直接继承 A 的进度
（Boss 都杀过了、地图都开了），换个方案体验另一套世界这件事就废了 ✓。现在改成：

- 点「**用这个方案玩**」= 把这个方案自己的存档换进游戏 → 挂载 → 起游戏 ✓
- **退出游戏后自动存回去** ✓（界面开着时每几秒看一次游戏进程 ✓；界面关着退出 ✓ 下次打开界面 1.5 秒后补存 ✓）
- 存档放在 **法魂包里的 `存档库\<方案名>\`** ✓（和 `方案\` 并排 ✓ 删游戏本体、换机器都不会丢 ✓）
- **任何覆盖 / 删除之前都会先留底** 到 `存档库\_回收\` ✓ —— 宁可多占 29 MB，也不赌一次手滑 ✓
- 第一次用某个方案玩会**先问你一句**「这个方案还没有存档，现在就用新角色启动吗？」✓
  选「否」= 什么都不动 ✓（继续用当前这份档）✓；选「是」= 旧档先归到「上一个方案」或 `_法魂本体` 槽 ✓ 再开新角色 ✓
  - 从方案目录里双击 **「用这个方案启动.bat」** 也算这条路 ✓ 一样换档 → 挂载 → 起游戏 → 退出回存 ✓（它的日志在层目录的 `启动日志.txt`）✓；**「切回法魂本体.bat」** = 删掉挂载 ✓

> ⚠️ **玩多套方案前把 Elden Ring 的 Steam 云存档关掉** ✓ —— 云同步可能在另一次启动把档换回去，这个工具管不着 Steam ✓。
>
> 游戏**正在运行**时也能直接点 ✓ —— 会先问一句「自动关掉它并启动吗」✓ 同意就替你关掉再开 ✓（先请它自己退 ✓ 实在不退才强杀 ✓ 强杀会丢最近一小段进度）✓。
>
> 详情面板多了「**存档**」两行 ✓：**方案存档**（这个方案自己的档：时间 / 大小 / 是不是现在挂着它）✓、
> **游戏存档**（游戏当前真正会读的那份：SteamID 目录 / 时间 / 大小）✓ —— 换没换对，一眼能看出来 ✓。

## 五点六、敌人随机（另一套玩法）

顶部第二个页签「**敌人随机**」✓ —— 把地图上摆着的敌人换成别的敌人：普通杂兵（含法魂新增的
无名杂兵）、野生生物、各种 BOSS 都能按你定的规则互换 ✓。物品与敌人可以**一次写入** ✓，也可以只改敌人 ✓。

### 先选一个预设
内置 **7 份预设** ✓（`investigation\enemy_presets\`，界面里也能直接选）✓：

| 预设 | 意思 |
|---|---|
| **01 参考默认·同族池** | 同类别内部换（杂兵换杂兵、BOSS 换 BOSS）✓ 最稳 |
| **02 BOSS 大乱斗** | BOSS 之间互换 ✓ |
| **03 杂兵大乱斗** | 杂兵之间互换 ✓ |
| **04 全员大乱斗** | 9 类一起混 ✓ 最疯 |
| **05 保守半随机** | 01 的 50% 版本 ✓ 只动一半位置 |
| **06 全Boss混池·杂兵同族** | 六类 BOSS 全部互相换（全 BOSS 池）✓ 杂兵只随同类、动物只随动物 ✓ |
| **07 Boss同类·杂兵同族** | 每个 BOSS 类只和自己同类换（Boss 只换 Boss、龙类只换龙类…）✓ 连有血条的真 BOSS 位也按同类换 ✓ 杂兵只随同类 ✓ |

### 难度分层：难 Boss 位多抽难池（2026-10-24 v1.3.17）
上一版的内置预设有两个毛病 ✓：4 个特殊池虽然能当来源，但 7 份预设一份都没用上 ✓；而且不分难度 ——
主要 BOSS 位和野外 BOSS 位抽的是同一套权重 ✓。这次重做 ✓：

- **特殊池当来源** ✓：每类的「换入来源百分比」里加入了 **追忆池 / 楔石池 / 传送门池** ✓
  （圣龛池只有 1 个 keep 成员，按设计不能当来源）✓；
- **按难度分层** ✓：主要 BOSS 位多抽追忆 / 楔石 ✓（02 里追忆 25% + 楔石 15%，01 里 14% + 9%）✓，
  野外 / 夜间 / 龙类 / 监牢位多抽野外池与同类 ✓，01 / 05 / 06 的杂兵仍然只随同类 ✓；
- **血条位 / 传送门位也吃预设了** ✓：以前这两类位置固定均匀抽，现在会沿用「这个位置原来是哪一类」的组成 ✓
  （追忆位就抽难池）✓；
- 分层是**概率倾向**不是硬规则 ✓：主要 BOSS 位仍有约 20% 会换到杂兵级 ✓ —— 想更狠或更保守，
  在编辑器里把某一类的追忆百分比调高 / 调低即可 ✓；
- 07 没改 ✓（它本来就是「同类型 Boss」语义）；旧的自定义预设不用改 ✓。7 份预设的实测构成见
  `docs/发布/更新日志_v1.3.17.md` ✓。

### 特殊池自己的位置也有来源了（2026-10-24 v1.3.18）
上一版只把特殊池当成「别的位置能换进谁」的来源 ✓，池自己那一组位置（追忆 48 / 楔石 18 / 传送门 27）
在预设里还是空的 ✓ —— 所以打开预设编辑器的「追忆 / 楔石 / 传送门」节点，池内位置的来源是 0 ⚠ 这次补上：

- **追忆 / 楔石位**：主要 BOSS 位偏难 ✓（02 里主要 18% + 追忆 40% + 楔石 32%；01 里 30% + 25% + 25%）✓；
- **传送门守门位**：以次要 / 野外 BOSS 为主 ✓（02：次要 30% / 野外 25% / 主要 25%）+ 少量追忆 / 楔石 ✓；
- **劳弗圣龛仍然不换** ✓：9 个变体共用同一个竞技场实体、阶段二事件依赖 SpEffect，换掉直接断事件 ——
  预设里是显式关掉（编辑器里能看到），不是漏了 ✓；
- **05 的池条目也只换 50%** ✓（与整份预设一致，所以换成的位置比上一版少 19 个）✓；
- 实测与变化见 `docs/发布/更新日志_v1.3.18.md` ✓。

### 区域缩放（换进来的敌人为什么不会离谱地强）
换入的敌人会按**它所在区域的强度档**重新算血量 / 攻击 / 防御 / 抗性 / 魂 ✓ —— 每个位置一条独立
SpEffect，挂在克隆行上 ✓ **原始表一行不改** ✓。所以：把盖利德的 BOSS 换到宁姆格福，它会**变弱** ✓；反过来变强 ✓。

BOSS 换进杂兵位还要再压一档 ✓（血 ×0.25 / 魂 ×0.25 / **攻击 ×0.5**）✓ ——
不然就是「血量像杂兵、打人还是 BOSS」✓。

> 2026-10-23 实机修过一次数值：法魂自造的特殊档（7131–7151 等）以前被当成「没有档 = 1.0」✓
> 于是蒙格自带的高倍率叠在区域档上 ✓ 出现过 **26,778 血** ✓。现在按**真实档位行**算 ✓

### Boss 数值平衡（2026-10-24 起自动带）

## 七、常见问题

**点了「用这个方案玩」，一点动静都没有？**

现在一般不用你先退游戏 ✓。两种常见情况：

- **覆盖层还没生成**：点一下就在后台生成（含敌人约 3 分钟）✓ 生成期间按钮变成「正在生成覆盖层…」并置灰 ✓ 生成完会**自动接着开局** ✓
- **游戏还开着**：会问你「自动关掉它并启动吗」✓ 同意就替你关掉再开 ✓（先请它自己退 ✓ 实在不退才强杀 ✓ 强杀会丢最近一小段进度）

两个都点了「否」= 什么都不动 ✓。真的一点动静都没有 ✓ 就看方案库底部那行小字（它会写卡在哪一步）✓。

**点启动提示「关不掉还在跑的游戏」，可任务管理器里又看不到游戏窗口？**

v1.3.9 起已经修了 ✓。原因是游戏退出后，任务管理器里会留下一个 `eldenring.exe` 的「空壳」
（线程/句柄都是 0、内存只有几十 KB，手动结束还会提示拒绝访问）—— 旧版把它当成游戏在跑，
于是每次都先问「要不要关掉游戏」，等 35 秒后报「关不掉」。新版会跳过这种空壳 ✓ 不用手动杀（也杀不掉，系统会自己收掉）✓。

**「编辑逐类预设」里怎么只剩 9 个类别了？法魂杂兵去哪了？**

v1.3.12 起调整的 ✓：**法魂杂兵并进了「常规敌人」**（同一档强度，池子更大），
另外 6 个分类（未分类 / 随从召唤物 / 复制体 / 假人测试体 / 粪金龟 / 商队巨魔）
不再显示、不再随机、也不当来源 ✓ —— 原因见上面「类别调整」一节 ✓。

**我自己改过的逐类预设要重做吗？**

不用 ✓。v1.3.12 载入预设时会自动迁移：旧「法魂杂兵」的百分比并进常规敌人，

**进游戏以后，每隔两三秒屏幕闪一个黑色终端框？**

v1.3.10 起已经修了 ✓。原因是工具在**等游戏退出**的时候，每 2 秒起一次 `tasklist` 查进程 ——
窗口版 exe 自己没有控制台，于是每查一次就新建一个黑框（一整局都在闪）✓。

换档换的是个游戏根本不读的文件 ✓ 所以你换方案 = 没换档 ✓。
