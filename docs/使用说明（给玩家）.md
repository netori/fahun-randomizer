# 法魂职业道具和装备随机器 · 使用说明

> 面向玩家。全程在本地运行，不联网。
> 作用一句话：**把职业说明书里的道具在合理范围内互相对调** —— 物品名不动，只换它现在所在的地点。

---

## 一、用之前要有什么

| 需要 | 说明 |
|---|---|
| **ELDEN RING** | 版本与你那份法魂本体一致（本版针对 1.17.1） |
| **「法魂」汉化本体 V3.0.3** | 本工具改的就是这份 MOD 的数据文件，**不能单独使用** |
| **你自己那份原版文件** | 就是你刚装好法魂时的那两个文件；工具会在**首次写入前自动备份**它们 |

⚠️ **本工具只支持中文版（法魂汉化本体）** ✗ —— 英文版或其它语言版**不适用** ✓。

---

## 二、安装（一步）

把 **`ConvergenceClassItemRandomizer.exe`** 放到 **MOD 根目录** ✓：
就是**含 `mod\regulation.bin` 的那一层** ✓（和 `mod` 文件夹、`启动法魂.bat` 并排）。

> 跟存档目录没关系 ✓；不需要 mod 管理器 ✓；不需要安装 ✓。

双击 exe ✓，出现界面 ✓。**先看「本地文件」那一块** ✓ —— 它会逐项自检：

| 条目 | 正常 | 缺了怎么办 |
|---|---|---|
| MOD 根目录 | ✓ 含 mod/regulation.bin | 点「**指定 MOD 目录…**」手动选 |
| 游戏物品数据 / 游戏说明书 | ✓ | 同上 |
| 目录可写 | ✓ | 换个位置（别放在 C:\Program Files 下）|

| 说明书基准（必需） | ✓ | 首次运行会**自动生成** ✓ |
| 随机引擎 | ✓ | 首次运行会**自动生成** ✓ |

## 四、三个选项怎么选

### 1）随机项目
勾你想动的：**卢恩** ✓ / **护甲** ✓ / **装备（武器）** ✓ —— 至少勾一项 ✓。

### 2）混合方式（勾多项时才需要想）
| 选项 | 意思 |
|---|---|
| **全部混合（勾选的几类一起混）** | 卢恩、护甲、武器**一起混** —— 变化最大 |
| **两两混 · 剩下独自**（三种） | 勾满三项时才会出现：比如"卢恩+护甲混，装备独自" |
| **各自随机（勾选的几类各随各的）** | 三类**各随各的**，互不掺和 —— 最保守 |

> 法师/祷告护甲**始终单独一组** ✓，无论选哪个都不会跟近战混 ✓。

### 3）合理度（0~100%）
一个滑块 ✓，但它同时控制三件事 ✓（界面下方那行绿字会实时告诉你是多少 ✓）：

- **越档幅度** —— 最远能跨几档（100% 只能同档互换 ✓，0% 完全放开 ✓）
- **越档率** —— 多少东西真的跨档（100% 时是 0% ✓）
- **武器掺入上限** —— 武器混进混池的比例（上限 66% ✓）

> **推荐**：第一次玩**先从 80% 开始** ✓（相邻两档可换 ✓、跨度 2/4 ✓、越档率 ≤20% ✓）
> —— 既有新鲜感，又不会出现"新手村捡到毕业装" ✓。

#### 3b）单池合理度（跟着混合方式自动出现）
> 就在**同一个「第 2 步 · 合理度」**里 ✓ —— 没有额外开关，该出现的自己会出现 ✓
> **没有勾选框**：行一出现滑块就在生效 ✓；**没动过的那些跟着总合理度走**（那行末尾会写「跟着总合理度」）✓

规则就三句，跟着「混合方式」和"勾了哪些随机项目"走：
- **有混池时**：上面那条**总合理度管混池** ✓，下面只摆"自己还成池"的那些类别 ✓。
- **全部混合**（三个类别都进了混池）：下面**一条都不摆** ✓ —— 只有总合理度 ✓。
- **各自随机**（没有混池）：**总合理度变灰**（那会儿它不参与）✓，**卢恩 / 护甲 / 装备**三条各管自己那一类 ✓。
- **两两混**：总合理度管那个混池 ✓，只有**落单那一类**有自己的那条 ✓。
- 没勾的随机项目不出现 ✓；**法祷护甲永远没有这一条** ✓（它不分等级，只在法祷内部互换）✓。

**每行都写着"这条现在会造成什么"** ✓（拖的时候实时变）：
> `相邻两档可互换　跨度 2/4　越档率 ≤20%` —— 跨度越大越容易跨档，越档率就是"能跨档的比例上限" ✓。

### 4）改动比例（勾了才展开）
> 在「更多设置」里 ✓ —— **没有勾选框**：行出现时滑块就在生效，**没动过＝这一类全改（100%）** ✓

只有两条，都是"抽一部分出来改"：
- **法祷职业护甲** —— **整套与散件一起**按这个比例改 ✓
  （例如 40% ≈ 四成法祷护甲参与互换，其余保持原样；"这次会改什么"里会给出换了几套、几件 ✓）。
- **商店物品** —— **有商店在卖的那批物品**里，多少参与互换 ✓（50% ≈ 一半货架会换）。
  它是按**物品**抽的 ✓：同一件东西既在货架上、也在宝箱/掉落里时，两处**一起换、一起不动** ✓
  （不这么做就会出现"货架换了、宝箱还是原来那件"）。
- 每行末尾写着当前值的效果 ✓（`全改（100%）` / `≈40% 的整套 / 散件参与互换`）。
- 取消「护甲」→ 法祷那条收起来 ✓；关掉「商店里的职业装备也一起换」→ 商店那条收起来 ✓。

> 例：法祷职业护甲 40% + 商店物品 100% → 法祷换四成左右，卢恩/武器照常全换，
> 商店卖的东西跟着它自己那件物品一起变 ✓。
>
> **它到底怎么生效的**（两个比例都是"抽子集"，都用种子决定，所以同种子可复现）：
> · 法祷护甲：在**每类池子里**抽 `round(池大小 × 比例)` 个单元，只在这个子集**内部**互换，没抽中的原样 ✓
> · 商店物品：先挑出"货架上有它"的物品，按比例抽其中一部分**参与互换**，其余的**整件**保持原样
>   （含它在宝箱/掉落里的那一份 —— 同一件东西必须两处一致）✓

### 5）法祷护甲整套一起换
> 在「更多设置」里 ✓

法师/祷告护甲**本来就不跟近战混** ✓；这一项决定它**内部**怎么换 ✓：
勾上 = **整套一起换** ✓（你拿到就是一整套 ✓）；不勾 = 按部位各自换 ✓。

> 法祷是个**大池子**：法师套 / 祷告套 / 混合套 / 感应套彼此互换 ——
> 所以可能在某处开出**别的法系**套装（比如原来放法师套的地方变成祷告套）。
> 这正是"法祷内部自由"的意思；要拦的只是"法祷 ↔ 近战" ✓。

### 6）种子
随便填一串数字 ✓（或点「换一个」✓）。**同一种子 = 完全一样的结果** ✓ ——
记下来就能复盘 ✓，也能发给朋友复现同一套世界 ✓。

## 五、正式使用（三步）

1. 点 **① 生成随机方案** ✓ —— 下面会显示「**这次会改什么**」：改了多少格、跨档情况等 ✓。
   再往下还有「**把什么换成了什么（前 300 条）**」✓ —— 想看具体哪件换到哪，就在那儿 ✓。**先看一眼再写** ✓。
2. 点 **② 写入游戏** ✓ —— 工具会：**先备份** → 复原成原始 → 写入新分布 → 重写职业说明书 ✓ 全程几十秒 ✓。
3. **进游戏** ✓，翻开任意职业的**说明书** ✓ —— 看到的物品名和原来一样 ✓，**地点全变了** ✓。

> （可选）这套玩得顺 ✓，就点一下 **「💾 保存到方案库」** ✓ 把它留下来 ✓ —— 见下一节 ✓。

## 五点五、方案库（保存你喜欢的那一套）

界面顶上两个页签 ✓：**⚙ 随机设置**（生成 / 写入）和 **📚 方案库**（管方案）✓。
方案存在 **MOD 目录下的 `plans` 文件夹**里 ✓ —— 不放进 exe ✓，**重装工具也不会丢** ✓。

方案库是**左边列表 + 右边详情** ✓：点左边一行 ✓，右边就是它的全部信息 ✓，
**名字 / 备注 / 标签点一下就能直接改** ✓（不用再点按钮、也不会弹框问你 ✓）。

| 想做什么 | 怎么做 |
|---|---|
| **把当前这套存下来** | 在「随机设置」页点「**💾 保存到方案库**」✓（生成之后才可点 ✓）—— 会自动跳到方案库并选中它 ✓，名字在右边直接改 ✓ |
| **换上某一套** | 选中它 → 「**写入游戏**」✓ 或**双击那一行** ✓（走的是和主界面**同一个**写入流程 ✓ 一样会自动备份 ✓）|
| **在旧方案基础上改** | 选中它 → 「载入到设置」✓ 参数会填回「随机设置」页 ✓ 改完重新生成 ✓ |
| **改名字 / 备注** | 右边面板里点一下直接改 ✓ 回车或点走就存 ✓ |
| **改标签** | 右边「+ 添加」→ 回车 ✓；点标签上的 ✕ 就去掉 ✓ |
| **收藏** | 「收藏 ★」✓ 收藏的会排在**最前面** ✓ |
| **复制一套再改** | 「复制一份」✓ |
| **删掉** | 「删除」✓ —— 会先移进 `plans\.trash` ✓ 底部会告诉你「已移到回收站」并给你一个**打开回收站**的入口 ✓ |
| **给朋友 / 备份** | 「导出…」成一个 `.json` ✓ 对方用「导入」即可 ✓ |
| **方案多了** | 上面搜索框按**名字 / 标签 / 备注**筛 ✓；右边还能按 时间 / 名字 / 改动量 排序 ✓ |

其余动作（改名 / 收藏 / 复制 / 删除 / 导出 / 导入 / 打开文件夹 / 刷新）在**列表上点右键**就有 ✓。

⚠️ 列表里若出现带 ⚠ 的条目 ✓ 说明那个文件损坏了 ✓ —— **其余方案照常可用** ✓ 不会因为一个坏文件整库打不开 ✓。

## 七、常见问题

**杀软提示 / 拦下载**
未签名的 exe ✓，属正常 ✓。加信任即可 ✓。工具**不联网** ✓、**不改游戏本体** ✓。

**点开没反应 / 界面白着**
第一次运行会生成工作文件 ✓，稍等几秒 ✓。若一直不动 ✓，看 exe 旁边有没有 `investigation` 文件夹 ✓。

**写入时报错说找不到 oo2core*.dll**
说明工具没自动找到游戏的 Oodle 库 ✓（正常情况下它会自己找到 ✓）。
做法：打开游戏安装目录里的 **`Game`** 文件夹 ✓，把里面的 **`oo2core_*_win64.dll`** 复制到
**exe 旁边的 `oodle` 文件夹** ✓（没有就新建一个 ✓）。放一次即可 ✓。

**能联机吗**
**不能** ✗，单人游戏专用 ✓。用之前请先备份存档 ✓。

**关了还能改回来吗**
能 ✓。点「还原成原始」✓（原始备份一直存在 exe 旁边的 `investigation\apply\backup` 里 ✓）。

| ✅ 说明书写的地点 | ❌ 物品名、字体、字号 |
| — | ❌ 数量、概率、价格、库存、解锁条件、事件流程 |

| — | ❌ 游戏本体（一个字节都不动） |

写入前**自动备份** ✓，写入后**自动审计** ✓，写入前还有一道**复核**（文件与方案对不上就直接中止 ✓，不会写一半 ✓）。
