# 法魂职业道具和装备随机器 v1.2.0

> 发布包：**`ConvergenceClassItemRandomizer.exe`**（英文名用 Convergence = 法魂）

给「法魂」MOD（THE CONVERGENCE V3.0.3 · 游戏 1.17.1 · YAFSML）用的物品随机化工具。
**原生实现，不依赖任何外部工具**（自研 AES / DCX / Oodle / BND4 / PARAM / FMG 读写）。

## 本版新增（v1.2.0）

- **法祷护甲与商店货架真的会换了** —— 上一版里它们**一件都不换**（池键少了"部位 / 套装"这一轴：
  整套与散件混在一个池里，而"整套只能与整套互换"，于是整个池找不到合法置换、被保守回退成"原样不动"）。
  本版把这一轴补回去，实测 **法祷护甲 355/355 行、商店 69/69 行全部参与**。
- **「这次会改什么」给出计数** —— 写在方案生成之后：换了几个商店货架、法祷护甲换了几套几件。
- **合理度表单定稿**（跟着混合方式自己变，没有多余开关）：
  - 有混池 → 上面那条**总合理度管混池**；下面只摆"自己还成池"的类别；
  - **全部混合** → 只剩总合理度（三个类别都进了混池）；
  - **各自随机** → 总合理度**置灰**，卢恩 / 护甲 / 装备三条各管自己那一类；
  - **没动过的那几条跟着总合理度走**（因此"不动它"＝"不设它"）。
- **每行实时写出量化效果** —— `相邻两档可互换　跨度 2/4　越档率 ≤20%`；
  比例那条写 `≈40% 的整套 / 散件参与互换`。单池设定**不再需要勾选框**（那行出现即生效）。
- **改动比例收敛成一条**（法祷职业护甲，整套 + 散件）；**商店没有比例条** ——
  勾上「商店里的职业装备也一起换」＝**在卖的职业装备全部参与**，不做二次抽。
- **方案库详情三段式**：随机设置 / 这次改了什么（分类明细：护甲 X，其中法祷整套 A 套 · 散件 B 件 · 卢恩 · 装备）/ 记录
  （引擎版本、指纹、保存 / 修改时间、**写入记录** —— 按方案指纹匹配写入收据）。详情区**可滚动**，
  窗口小也看得全，底部按钮固定。
- **方案库写入反馈修好** —— 以前从方案库点「写入游戏」会一直停在"写入中"（其实早就写完了，
  只是进度只回显在主界面那一页）；现在进度与结果都回显在方案库窗口，并挡住重复点击。

## 本版修复的坑

- **生成偶发失败** — 生成线程里读了 Tk 变量，会撞上 `main thread is not in main loop`；改成在主线程收参数。
- **表单不联动** — 换「混合方式」时下面两组不刷新（下拉框没绑刷新）；开关「商店 / 整套一起换」不带动比例那一组。
  连带修掉一处**重复定义**（同名的刷新函数有两份，后一份覆盖前一份，导致提示文字永远不会更新）。
- **取消类别后混合方式被顶回"全部混合"** — 原来按"整串文字"记住当前选项，而文字里嵌着类别名；现改为按**意图**归类。

## 验证记录（本版发布前实测）

- 矩阵测试：15 配置 × 6 种子 = **90 组全部通过**（6 项引擎校验 / 守恒 / 同种子可复现 / 法祷零违规 / 压缩帧校验）
- 负例回归：**30 项**全过（含"同职业多页首行相同 → 串页"这个真实 bug 的回归、商店比例的一致性）
- **旋钮体检**：每个配置项各跑一对配置验"结果真的变了" —— **18 项有效 / 0 异常 / 2 项已知空转**
- **写入侧体检**（临时 MOD 副本上真跑写入与还原）：说明书开关两个方向、商店行**只动 `equipId` / `equipType`**、
  还原成原始**逐字节复原** —— 5/5 通过
- 界面自检：`--uicheck` / `--uitest` / `--planlib` / `--selftest` 四道全过

## 怎么用

1. 把 `ConvergenceClassItemRandomizer.exe` 放到 **MOD 根目录**（该目录下应有 `mod\regulation.bin`），双击打开
2. 「**本地文件**」会逐项自检：MOD 目录、游戏数据、说明书、原始备份、说明书基准、随机引擎
   - 有 ✗ 时「写入游戏」会被禁用；可按提示「指定 MOD 目录…」或「补一份原始备份」
3. 选**随机项目**（卢恩 / 护甲 / 装备，至少一项）→ 选**混合方式**
4. 拉**合理度**、填**随机种子**（或点「换一个」）
5. 点 **① 生成随机方案** → 看「这次会改什么」→ 点 **② 写入游戏**
6. 不满意：点 **还原成原始**（写入前的备份会自动保存，随时可回退）

## 核心行为（未变）

- **只换物品，不搬位置**：格子、数量、概率、价格、库存、解锁、事件流程一律不动
- **范围 = 职业说明书**：只有说明书里出现的物品参与（商店默认不参与，可开启；
  商店开启时也只影响说明书里那批职业装备 —— **价格 / 限量 / 解锁条件一个字节都不动**）
- **同一种子 = 完全一样的结果**
- **档位**：卢恩 学徒0 / 熟练1 / 精通2 / 大师·幽影3；护甲 臂0 / 腿1 / 身2 / 头3；武器按所在地区 0~3
- **法师 / 祷告护甲**始终单独成池，永不进混池
- 改完物品后**说明书跟着改**（物品名不动，只换它现在所在的地点），每次写入自动审计 8 项

## 已知限制

- 法祷**护甲**按部位分为 4 个池（法祷臂甲只换法祷臂甲）；法祷护甲**不分等级**（合理度对它没有意义）
- 说明书里约 3 成地点在没有可读中文名的点位上会保留原地点
- 平台上传与在线分发不在本工具范围内（只出本地发行物）
