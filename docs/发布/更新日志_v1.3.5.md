# 更新日志 v1.3.5（2026-10-23）

## 修「随机后点『用这个方案玩』没反应」

**原因**：游戏还开着。启动器要换档 + 挂载，必须先把游戏关掉，代码里确实拦住了 ——
但旧版只把原因写到方案库底部那一行小字（toast），窗口一大就很容易看不见，于是像「没反应」。

**这一版改成**：

1. **所有被拦下来的情况都会弹框**，并把下一步写清楚：
   - 游戏正在运行 → 「启动器要换档 + 挂载，必须先把游戏关掉；覆盖层已经生成好了 —— 退出游戏后再点一次就行」；
   - 正在生成覆盖层 → 「等它跑完，生成完会自动接着开局」；
   - 别的写入任务还没跑完 → 明确说等它结束；
   - 覆盖层生成失败 → 弹框 + 日志（以前只有底部一行字）。
2. **生成覆盖层不再要求先退游戏**：覆盖层只读原始基底、不碰法魂本体，
   所以点「用这个方案玩」会**立刻在后台开始生成**（含敌人时约 3 分钟），
   生成完再提示「退出游戏后点一次就能玩」；等游戏退了再点，因为层已就绪，直接换档开局。
3. 生成期间按钮变成 **「正在生成覆盖层…」且置灰**，不会重复点出一堆任务。
4. 生成失败后按钮自动恢复，不用重开界面。

  下次点（游戏退出后）直接走到换档 → 挂载 → 起游戏，不会再等一次 3 分钟。
