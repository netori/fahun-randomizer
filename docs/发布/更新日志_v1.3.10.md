# 更新日志 v1.3.10（2026-10-23 晚）

这一版修两个**一直反复出现**的问题，都是作者（玩家侧）实测报上来的：

1. **用随机器 / 方案层脚本启动时，会反复跳出黑色终端窗口**（一整局每隔两三秒闪一下）
2. **「独立存档」没有真正生效** —— 每个方案看起来有自己的档，游戏里读到的却不是它

两个都修了，并且这次是拿**真游戏**验证过的。

---

## 一、反复跳终端

### 现象

用「用这个方案玩」（或方案层目录里的启动脚本）进游戏后，**每隔 2~3 秒屏幕闪一个黑色终端框**，
一整局不停。游戏本身没事，但非常影响体验，还容易误以为是木马/报错。

### 根因

工具在**等游戏退出**，靠的是一个"游戏还在不在跑"的判断。旧写法每判断一次就起一个
`tasklist.exe` 去查进程（窗口版 exe 自己没有控制台，所以每调一次就**新建一个控制台窗口** ——
一闪；判断一次闪一次，2 秒一次，于是整局都在闪）。

### 修法

- 查进程改成直接问系统的进程快照（`CreateToolhelp32Snapshot`，ctypes），**不再起子进程** → 不再有黑框；
- 实在要用命令行的地方（关游戏）也统一加 `CREATE_NO_WINDOW`，窗口不会冒出来；
- 启动法魂的 `启动法魂.bat` 由"弹一个 cmd"改成隐藏窗口调用。

### 验证

打包版 exe 在真机上跑了一次 `--play`（游戏 7.7 秒起来、进了游戏内、约 65 秒后关掉）：
轮询全程**新起的控制台进程 = 0 个**（只有启动那一下 1 个 `cmd` + 1 个 `conhost` 用于起法魂，
`tasklist` 一次都没再起）。旧版是每 2 秒一次 —— 一整局都在闪。

## 二、独立存档没生效

### 现象

方案库里每个方案都有"自己的存档"，界面上也显示"已存回它的槽"，
但进游戏看到的角色还是老样子 —— 换方案等于没换档。

### 根因（关键）

法魂包的 `yafsml\YAFSML.ini` 里有这两行：

```ini
replace_save_filename=.cnv
replace_seamless_coop_save_filename=.cnv.co2
```

（行首是点号 = **只替换扩展名**）—— YAFSML 会让游戏把 `ER0000.sl2` **改名成 `ER0000.cnv`** 去读写。

而工具以前只认死 `ER0000.sl2` / `ER0000.sl2.bak`：

- 换档 → 换的是 `ER0000.sl2`，游戏**根本不读这个文件** → 看起来换成功，实际没换；
- 退出回存 → 存的也是那个游戏没碰过的老 `.sl2` → 进度永远停在旧样子；
- 玩家真实进度全在 `ER0000.cnv` 里，一次都没被存进槽。

### 修法

- 存档文件名**从 YAFSML.ini 现读**（`replace_save_filename` / `replace_seamless_coop_save_filename`，
  点号开头按"只换扩展名"展开）—— 不写死；
- 存槽 / 换档 / 留底 / 清档 / 回存 / 切回本体全部按**配置里的名字**工作，成对换（连 `.bak` 一起）；
- **老存档自动迁移**：以前存在存档库里的 `.sl2` 槽，第一次运行时自动改名成 `.cnv`（内容不动，
  改之前先复制一份进 `存档库\_回收\`，且幂等 —— 迁过的不会再迁）；
- 「切回法魂本体」现在**真的换档**：先把当前方案的进度存回它的槽、再把本体档换进游戏存档目录
  （以前只清 `Plan=`，于是"切回本体"玩到的还是上一个方案的档）。

### 验证（真机真档）

- 迁移：live 的 `ER0000.cnv`（19:20 那次游戏亲手写的进度，SHA1 `ee13396…`）归位到方案槽；
  本体槽的 `.sl2`（10-21 的档）改名为 `.cnv`；两份旧文件都进了 `_回收`；
- 端到端（不起游戏）：切回本体 → live 变成本体档（`f33062…`）→ 再点该方案 → live 变回方案档（`ee13396…`）；
- 真游戏启动一次：游戏读写的是 `ER0000.cnv`，退出后 `finish()` 存回方案槽。

**如果你是老版本升上来**：什么都不用做。第一次打开工具 / 第一次开玩时，
存档库里的旧 `.sl2` 会自动改名成 `.cnv`（`_回收` 里会留一份原文件，反悔可以拿回来）。
唯一要注意的：**别同时开两个"读同一个存档目录"的游戏/工具**，换档是直接替换文件。

## 三、怎么升级

覆盖 exe 即可（`ConvergenceClassItemRandomizer.exe`）。方案库（`plans\`）与存档库（`存档库\`）
都不受影响；第一次运行会自动把老存档槽改名（见上）。

---

## 四、已知边界（这一版没做）

- 无缝联机档（`.co2`）只识别、**不参与换档**（独立存档只管单人档）；
- 存档槽与 live 是"整个文件替换"，游戏运行中不要手动拷档；
- 法魂包升级 / 换整合包时，如果 `YAFSML.ini` 的改名配置变了，工具会按新配置走 ——
  旧槽不会自动改回去（要的话从 `_回收` 拿）。
