# 更新日志 v1.3.4（2026-10-23）

## 一、这一版的核心变化：随机只造方案，开玩时才生成覆盖层

以前：点「开始随机」当场把覆盖层建出来、挂上 → 再到方案库开玩。
现在（按 2026-10-23 的要求改成）：

1. **点「开始随机…」= 只生成一套方案，并自动存进方案库** ——
   不写盘、不建层、不挂载、不碰法魂本体。
2. **到方案库双击那一行 = 用这个方案玩** ——
   需要时在后台按需生成覆盖层（`方案\<层名>\mod\`）→ 换档 → 挂载 → 起游戏；
   覆盖层已是最新且设置没变就跳过构建，直接开局。
3. **覆盖层只从「原始版 regulation」构建**，法魂本体的
   `mod\regulation.bin` 与 `msg\zhocn\item_dlc02.msgbnd.dcx` 全程零写入。

## 二、界面

- 底栏只剩三样：**「开始随机物品 / 敌人 / 物品和敌人」**（文案随勾选实时变）·
  **「打开方案库」** · **「还原成原始」**。
- 删除的按钮 / 表单：「💾 保存到方案库」「写入游戏」「启动游戏」、
  敌人页重复的部署入口、以及「只在方案层里生成」勾选框（现在恒为方案层模式）。
- 敌人页右卡 = 「当前方案 / 挂载状态」+「用这个方案玩」（跳到方案库）+「切回法魂本体」。
- 方案库：
  - **双击一行 = 用这个方案玩**（不是写入，防误触）；
  - 详情主按钮 = 「用这个方案玩」，「写入游戏」按钮已删除；
  - 「记录」段把原来的「写入记录」换成 **「覆盖层」状态**：
    「还没生成 —— 第一次点用这个方案玩时自动生成」/「已生成 · 时间」/「设置改过 —— 下次开玩会重新生成」。
  - 列表第二行显示类型（物品 / 敌人 / 物品+敌人）与行数；敌人方案写「开玩时生成」。
- 空库引导改成「点底部的开始随机… —— 生成的方案会自动存到这里。双击一行就开始玩」。

## 三、行为细节

- 生成成功后自动跳到方案库并选中新方案，状态栏 / 浮层说明下一步。
- 只勾「敌人随机」：存的是一个**敌人方案**（没有物品行），开玩时用原始基底建一个只有敌人的层。
- 每次「开始随机…」都会存成**新的一条**方案，旧的留着；想在同一套上改就用「载入到设置」。
- 游戏正在运行时拒绝开玩（防止运行中换档写坏存档）。
- 每个方案一份独立存档；第一次用某个方案玩会问一次「用新角色开局吗」，
  旧档先留底在 `存档库\_回收\`（这一套是 v1.3.0 起就有的，本版只是把它接到新流程上）。
- 覆盖层目录名 = `方案_<方案名前 20 字>_<id 后 6 位>`；**方案改名不会改目录**，存档槽跟着目录走，不会丢。
- 覆盖层是否需要重建的判据：目录里 `mod\` 在 + 构建记录在 + 方案指纹一致 + 敌人设置的签名一致。

## 五、升级注意

- 旧版存的方案没有「覆盖层」记录：第一次双击会按需生成一份新层（旧层仍留在 `方案\` 里，可手动删）。
- v1.3.3 及更早的流程会把物品直接写进本体（或提前建好层）。想彻底回到「本体干净」的状态：
  先退出游戏 → 点一次 **「还原成原始」** → 之后都用方案库开玩。
- 本体里留着老随机也能玩（覆盖层会盖住它），只是不推荐——两种改法混着不容易判断问题出在哪。
