# 更新日志 v1.3.12（2026-10-24）

> 一句话：**敌人类别表收干净了** —— 16 类 → 界面上 9 类。
> 「法魂杂兵」并入「常规敌人」（池子变大、强度同档），
> 「未分类 / 随从/召唤物 / 复制体 / 假人/测试体 / 粪金龟 / 商队巨魔」不再出现在界面上，
> 也不再参与随机、不再当来源。旧预设自动迁移，不用手动改。

---

## 一、为什么改

作者看「编辑逐类预设」时提了两点：

1. **法魂杂兵（旧 Mob 类）应该归入常规敌人** —— 它们本来就是法魂新增的无名杂兵（统一名
   「法魂杂兵（cXXXX）」），和普通杂兵同一档强度、同一类位置，单列一类只会把池子拆小。
2. **几个分类没用**：商店巨魔（商队巨魔）、假人/测试体、复制体、随从/召唤物、未分类、粪金龟。
   它们在随机里要么从来不动（keep），要么换了没意义/会断链，占着界面的位置。

## 二、改了什么

### 1）分类表（`investigation/apply/data/enemy_classes_v3.yaml`）

| 旧 | 现状 |
|---|---|
| Basic 14,892 + Mob 329 | **Basic 15,221 个位置**（Mob 并入；`class_aliases: {Mob: Basic}`） |
| Scarab 220（参与随机） | 内部标记类：**keep**（粪金龟只是掉落容器，换了没意义） |
| CaravanTroll 12（参与随机） | 内部标记类：**keep**（跟着商队路线走，换了断商队） |
| None / Helper / DupeOnly / Dummy | 原本就 keep；现在标 `ui: false`，**界面不再显示、不当来源** |

- 界面上剩下 **9 类**：常规敌人 / 被动野生动物 / 敌对型人类 / 主要BOSS / 次要BOSS /
  野外BOSS / 夜间BOSS / 龙类BOSS / 封印监牢BOSS。
- 删除两条规则：`scarab`（粪金龟）、`caravan_troll`（商队巨魔）；`fauna` 的候选从
  [Basic, Wildlife, Mob] 收成 [Basic, Wildlife]。
- 内部标记类仍是位置表里的合法类名（只用来标记「这个位置不能动」），所以老计划/老层照旧能读。

### 2）数据表重建

`enemy_data_build.py --build` 重算 27,780 行位置表 + 462 个模型名字表：

- `policy=randomize` 24,652 → **24,409**（-243：粪金龟 220 + 商队巨魔 12，其余是重复 MSB 联动）；
- `policy=keep` 3,128 → **3,371**；
- 类分布：Basic 15,221 / Wildlife 9,133 / None 2,244 / Helper 440 / Scarab 220 /
  DupeOnly 171 / Boss 117 / MinorBoss 75 / HostileNPC 49 / Miniboss 39 / NightMiniboss 24 /
  DragonMiniboss 15 / Dummy 12 / CaravanTroll 12 / Evergaol 8；
- `--check` 全 PASS（含新增两条不变式：位置表里不能残留旧类名、`ui:false` 的类必须全 keep）；
- `enemy_plan.py --selftest` 全 PASS（25,656 单元 / 替换 22,460 / 跳过 3,196；预设、来源百分比、
  多阶段、oops、敌人倍增各条都在）；5 份内置预设逐一构建 + `validate_plan` 全 PASS
  （01–04 各替换 22,460 / 位置 24,409，05 替换 11,290 / 位置 12,268；0 错误）。

### 3）预设迁移（旧预设不用手动改）

- `normalize_preset()` 先过 `migrate_preset_classes()`：
  - 旧 `Mob` 条目的**来源百分比并进 Basic**（targets / donor_weights 一起合并）；
  - 内部标记类（`ui:false`）的条目直接丢弃，不再作为来源；
  - 合并后 weight 超过 100 的按比例整体缩回（保持类别间比例）。
- 编辑器载入/应用时自动走迁移；磁盘上 5 份预设（01–05）已就地迁移（现在都是 9 类）。
- 旧计划 JSON 不需要迁移：计划里出现过的类名仍是合法数据，写盘/复验照常。

### 4）界面（编辑逐类预设）

- 左边类别树按 yaml 现算（9 个），标题「%d 个类别 / %d 个分组 / %d 个模型」不再写死 16/19；
- 「全替换为」下拉也按可见类现算；
- 「只同族」按钮：BOSS 六类一组，常规敌人 ↔ 被动野生动物一组；
- 自检新增两条：类别数 = 9、树里不再出现「法魂杂兵/粪金龟/商队巨魔/未分类/假人/随从/复制体」。

## 三、升级

换 exe 即可（v1.3.11 → v1.3.12 无存档格式变更）。**旧方案层/旧计划不用动**；
下次点「开始随机」会按新分类表出计划（常规敌人池变大、粪金龟/商队巨魔保持原样）。

## 四、边界

- 「删掉分类」= 从**随机与界面**里删掉；位置表内部还留着这些类名当「不能动」的标记 ——
  否则这些位置会被当成未知类，校验会 fail。
- 敌对型人类（HostileNPC，49 个位置）仍是全部 keep：它们都是事件生成的入侵者（c0000 空壳），
  v1 不动，所以界面上虽然有这一类，实际换不到（点开显示 49 个位置组但都带 keep 原因）。
