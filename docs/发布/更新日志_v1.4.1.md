# v1.4.1 更新日志（2026-10-25）

## 一句话

两处数值/预设修正：**「杂兵位换成 Boss」不再被扣两次血**（以前实际只有位置原血量的约 0.25，现在是位置原强度 ±25%）；**7 份内置预设里凡是引用特殊池的组成，都补齐了全部 4 个特殊池**（追忆 / 楔石 / 传送门 / 圣龛），并在自检里加了防漏断言。本版不改数据表、不改界面，只改计划层/写盘层的数值口径与 6 份预设 JSON。

## 为什么改（原话）

- 2026-10-25 用户：「先尝试多种配置随机敌人，看看数值是否合理」→ 12 套配置离线审计（见下文数字），发现 Boss 进杂兵位被双重缩放。
- 2026-10-25 用户：「那修一下吧，修完确定一下，预设不要再漏掉任何一个特殊池子」——本版两件事都做完。

## 一、修：「杂兵位换成 Boss」被双重缩放

**机制（修前）**：写盘层对 `rel=b2m`（旧普通敌人 → 新 Boss）的克隆行已有一次降级 —— `AREA_BOSS_AS_BASIC_FACTORS` 里 `health ×0.25`（照顾位置本身是杂兵位：Boss 的原始血量太厚）。同时计划层的数值平衡（`enemy_balance.apply_to_plan`）会把这类单元的 `target_hp` 锚到「位置原有效血量 h」的 0.85~1.25 倍 —— 但它锚的是**写盘前**的值，写盘时又被乘一次 0.25。两次叠加的实际有效血量 = **0.25 × h**（审计实测 0.21~0.31×）。

| 配置（seed 20261025） | 位置 | 修前实际比例 | 修后实际比例 |
|---|---|---|---|
| 01 参考默认·同族池 · 杂兵位→Boss | 29 | ≈0.25×（0.21~0.31，双重缩放） | **0.86× ~ 1.14×（p50 0.98×）** |
| 04 全员大乱斗 · 杂兵位→Boss | 983 | ≈0.25× | **0.85× ~ 1.25×（p50 1.00×）** |
| 02 / 03 / 05 / 06 / 07 / 内置规则 · 杂兵位→Boss | 16~29 | ≈0.25× | **0.85× ~ 1.25×** |

**修法**：

- `enemy_balance.py` 新增 `B2M_HP_FACTOR=0.25` / `B2M_XP_FACTOR=0.25` / `B2M_DAMAGE_FACTOR=0.5` 三个常量，和新增的 `rel_of(unit)`（与写盘层同一口径）；
- `apply_to_plan` 在有区域档时把分母除以 `B2M_HP_FACTOR`：`target = round(h / (dst_rate × 0.25))` → 写盘再 ×0.25 后正好回到 h（平衡窗口 ±25% 内）；无区域档的位置不动（没有 region effect 也就没有那次 0.25）；
- `enemy_write.AREA_BOSS_AS_BASIC_FACTORS` 改为直接引用 `enemy_balance` 的常量 —— **单一来源**，以后调一个数不会再出现两处不一致。

**顺带修的多阶段误判**：`enemy_write._rel_of` 以前只看 `cls in BOSSISH` —— 多阶段 Boss 的「二阶段 / 化身」实体在位置表里是 Helper / Basic 类，于是也被判成 b2m，白吃一次 −75% 血 + 伤害减半。v1.4.0 的默认计划里 **36 个 b2m 单元有 8 个是这种**（女武神二阶段 15000806、幽影树化身 22000801、米德拉 2050480800、幽影树 2050480801~805）。修后 `rel_of` 对 `multiphase` / `duo` 一律算 Boss 侧：这些位置的 b2m 消失，血量与伤害回到正常。b2m 单元数 36 → 28。

**残余说明（设计如此）**：`Boss→Normal`（Boss 位置换成普通敌人 = 大幅削弱）在 03/04 这类「乱斗」预设里会出现小比例、低比值（04 有 55 个，p5 0.02×）——那是「让 Boss 位也可能变杂兵」的预期效果，不是本次的 bug；想避免就用 01/05/06 这类保守预设。

## 二、修：内置预设漏特殊池

**问题**：特殊池当来源是 v1.3.17 做的，当时只有 3 个池（追忆 / 楔石 / 传送门）；v1.3.19 把**圣龛**（`reliquary`，成员只有劳弗仪卫 c2195）也变成可当来源后，7 份内置预设的组成普遍没接它；另外 03 的组成原本只接了 Boss 类 + 追忆/楔石，传送门与圣龛也漏。结果：**被漏掉的池的成员，永远不会出现在那一类位置的换入候选里**。

**规则（本版落地）**：任何一处组成（类条目 / 池条目 / 血条位）**只要引用了至少一个特殊池，就必须引用全部 4 个**（权重可以不同）。理由：池是「成员集合」，不是类；只接一半等于那个池的存在感被悄悄抹掉。

**改动（6 份预设 JSON，07 不动）**：

| 预设 | 补了哪些组成的池引用 |
|---|---|
| `01 参考默认·同族池` | Boss/MinorBoss +圣龛；Miniboss +追忆/圣龛；夜间/龙类/封印监牢 Boss +楔石/追忆/圣龛；4 个池条目互相补全 |
| `02 Boss大乱斗` | 同 01 |
| `06 全Boss混池·杂兵同族` | 同 01 |
| `05 保守半随机` | 同 01 |
| `03 杂兵大乱斗` | Boss +传送门/圣龛；4 个池条目各 +传送门/圣龛（原来只有追忆/楔石） |
| `04 全员大乱斗` | 常规/野生动物/Boss/次要 Boss +圣龛；更少见的 Boss 类 +楔石/追忆/圣龛；池条目互相补全 |
| `07 Boss同类·杂兵同族` | **不动**：它用「@sameboss」表达「只换同一种 Boss」，没有任何特殊池引用，天然通过 |

**权重**：新增池的默认权重 = 楔石/追忆/传送门 3、圣龛 5（圣龛只有 1 个身份，Boss 使用上限会天然限次）；原有 `donor_weights` 等比缩到总和 100（保留 1 位小数，残差记在最大项）。**池条目自己的 `targets` 也同步补全**，保证「池内位置选来源」时四个池都能互相流通。

**防再犯**：`enemy_plan.py` 新增 `preset_special_pool_gaps(preset, cfg)`（返回缺失清单），`--selftest` 末尾加载 `investigation/enemy_presets/*.json` 断言「引用特殊池的组成都包含全部 4 个池」——以后再漏会直接让自检失败。**自定义预设不受强制**（GUI 里存的是你自己的取舍，本版只保证内置 7 份完整）。

## 四、兼容 / 升级

- **数据表不用重建**（`enemy_places.csv` / `enemy_model_names.csv` / yaml 都不动）。
- **旧的自定义预设不用改**；想用新组成就从「预设」里重新选一次内置预设。
- 计划层/写盘层改的是**数值锚点**：同一 seed 的具体换入结果不变（换谁没变），只有 b2m 单元的 `target_hp` 变大（回到位置原强度）。
- 版本号只体现在包名/文档名（exe 无内嵌版本常量）。

## 五、风险与回退

- 风险：杂兵位换成 Boss 后**血量比修前厚约 4 倍**（本身 ±25% 平衡窗口还在）——这是修正本意（以前太软）；如果实际玩起来觉得「杂兵位的 Boss 太肉」，可在界面调低这类位置的换入比例，或用 05 保守预设。
- 回退：把 `enemy_balance.B2M_HP_FACTOR` 改回 1.0 即可退回旧口径（写盘层跟着变，因为已单一来源）；预设想回旧组成就把 6 份 JSON 换回 v1.4.0 的。

## 六、边界

- 界面无改动，没有新开关。
- 自定义预设不强制补池（只在自检里保证内置 7 份）。
- \`Boss→Normal\` 的极低比值是乱斗预设的预期效果，不在本次修复范围。
- 完整验收仍要靠人进游戏（`docs\敌人随机_试玩验收清单.md`）。
