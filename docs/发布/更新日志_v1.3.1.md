# 更新日志 · v1.3.1（2026-10-23）

> 上一版 v1.3.0 是今天上午发的。这一版只改**界面与交互**：删掉已经停用的老表单，
> 把动作按页收进各自的页面。随机引擎、写盘逻辑、方案与存档都一个字节没动 ——
> 用旧方案直接开局即可。

## 一、删掉的无用表单

- **旧敌人管线（v0）整块删除**（不是折叠藏起来）：总开关、游戏进程、敌人摆放、法魂专属、未接项，
  以及右下角与 v1 重复的三个按钮，连同它们背后已经不再被部署流程读取的控件变量一起删掉。
- 物品页「结果」卡里常显的三条「小提示」删掉（与底栏、按钮旁注重复）。
- 敌人页六行常显的「当前生效的规则」压成一行摘要（详细规则仍在 README / 文档里）。
- 物品页「本地文件」7 项诊断清单收进「**逐项详情 ▸**」，平时只显示「N / N 项通过」。
- 敌人页左卡上重复的「用这个方案玩」删掉（右列「当前方案」卡已有）。

## 二、交互：动作跟着页走

- **物品页**：生成 / 写入 / 还原 / 保存到方案库 / 启动游戏仍在这一页底部固定条上；
  切到另外两页时**整条底栏收起**（原来在敌人页也显示"本次写入 物品…"的摘要，容易误以为是当前页的动作）。
- **敌人页**：只剩一个生成入口「**生成方案层并应用**」（物品页有方案就一次写入物品 + 敌人，
  没有就只写敌人）；挂载状态与「用这个方案玩 / 切回法魂本体」集中在右列「当前方案」卡。
- **方案库**：
  - **双击一行 = 用这个方案玩**（以前是直接写入游戏 —— 双击是"打开"的语义，不该触发破坏性动作）；
  - 详情面板主按钮换成「**用这个方案玩**」，「写入游戏」降为次按钮；
  - 副标题改成「点一行看详情，双击用这个方案玩」。
- 物品页环境卡改成一行；旧的"生成 / 写入 / 还原 都在窗口底部"文案按新布局改写。

## 三、验证

- 界面自检：--uicheck（构建 + 12 项对比度 + 装饰件 5/5）、--uitest 全绿；
  新增断言覆盖：旧管线死表单已删、敌人页只剩一套控件、底栏随页签收起、按钮主次、双击语义。
- 引擎自检：--selftest（同种子可复现 / 换种子不同）、--planlib（方案库读写）全过。
- 三页截图逐页看过（说明卡文字不再被裁切、动作不再重复）。
