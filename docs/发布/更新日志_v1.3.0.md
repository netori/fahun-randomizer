# 更新日志 · v1.3.0（2026-10-23）

> 上一版 v1.2.0 是 2026-10-15 发的。这一版把「敌人随机」整条流水线做了出来，
> 并且给方案库加了**直接用方案开局 + 每个方案独立存档**。

## 一、敌人随机（新页签）

- **整条 v1 流水线**：按位置重排敌人 —— 497 张图 / 24,421 个位置 / 22,470 个替换单元；
  改的是**克隆行**（NpcParam 7,830 → 25,963 行，+18,133 条），原表一行不动。
- **四个特殊池**：传送门 / 钥石 / 追忆 / 圣龛；**逐类来源百分比**（每个目标类一组来源，多来源叠加）。
- **5 份预设**：01 参考默认·同族池 / 02 BOSS 大乱斗 / 03 杂兵大乱斗 / 04 全员大乱斗 / 05 保守半随机。
- **BOSS 血条名跟着换**：178 张图 / 211 个位置实际改名（按位置替换 EMEVD 字面量，含 30 张本体事件兜底图）。
- **多阶段 BOSS 血量**：荷莱露 p2 2675 / 玛利喀斯 857+1049 / 火焰巨人 9095→**5045** / 梅瑟莫 1481+1482 / 拉达冈 1108+2060。
- **区域缩放**：换入的敌人按所在区域的强度档重算血量 / 攻击 / 防御 / 抗性 / 魂（每个位置一条独立 SpEffect，挂在克隆行上）。
  BOSS 换进杂兵位再压一档：血 ×0.25 / 魂 ×0.25 / **攻击 ×0.5**（2026-10-23 实测追加）。
- **特殊档修正**：法魂自造档（7131–7151 等）不再被当成「没有档 = 1.0」—— 蒙格那一例从 26,778 血修到 **4,041 血 / 攻击 ×2.58**。
- **手动指定**：CSV（map,entity_id,npc_id,model,note），优先于一切规则；找不到目标会如实报错。
- **实验项（默认关）**：多阶段 BOSS 整组替换 / 敌人颜色 / 敌人倍增。

## 二、一次写入：物品 + 敌人

- 「敌人随机」页 v1 卡片上的 **「①+② 物品+敌人一次写」**：先写物品 → 从这份本体构建敌人层 → 只挂一个层。
- 不再需要写两次，也不会出现「后点的把先点的顶掉」。

## 三、方案库：用这个方案玩 + 每个方案独立存档

- 以前所有方案共用一份存档（在 A 玩到 60 级，切到 B 就继承 A 的进度）。现在：
  **点「用这个方案玩」= 换档 → 挂载 → 起游戏**；退出游戏后进度自动存回这个方案的槽。
- 存档库在法魂包 存档库\<方案名>\（和 方案\ 并排）：ER0000.sl2 + .bak + slot.json。
- **任何覆盖 / 删除之前先留底**到 存档库\_回收\；第一次用某方案玩会先问「开新角色吗」。
- 详情面板新增「**存档**」两行：方案存档（时间/大小/是否正在挂着它）、游戏存档（SteamID 目录/时间/大小）。
- ⚠️ 玩多套方案前请关掉 Elden Ring 的 **Steam 云存档**。

## 四、稳定性

- 修掉「挂载区域缩放层后启动崩溃」（0xc0000409 / ucrtbase，参数表 rebuild 漏写头部 0x48/0x50 两个同义副本字段）。
- 写完复验：`--verify` PASS（497 图 / 24,421 位置 / 25,963 行 / 18,133 克隆 / 390 条 SpEffect / 多阶段 8 行）。
- 实机：启动 → title → 进存档 → 跑图遇敌战斗连续 2 分半无崩溃；随后 F 层启动 ALIVE 85s+。

## 六、升级注意

- 把新 exe 覆盖旧 exe 即可（方案库 `plans\` 与 `存档库\` 都不会被动）。
- 用方案库启动之前，先让游戏**退出**（运行中换档会被拒绝）。
- 旧方案层仍可用；想回纯本体点「切回法魂本体」。
