### 一步推上去（在你的机器上，任意终端）


```bat
git log --oneline -3                        :: 看本地是不是最新
git ls-remote --heads origin                :: 看远端 main 的哈希是否与你本地 HEAD 一致
```

```bat

```

## 二、N网（Nexus Mods）

**入口**：登录后右上头像 → **Upload a mod**（或 <https://www.nexusmods.com/users/myaccount?tab=upload>）。

1. **选游戏**：Elden Ring → **选分类**：`Modding Tools / Utilities`。
2. **上传文件**：`发布包/ConvergenceClassItemRandomizer_v1.0.0.zip`（17 MB，里面是 exe + 使用说明 + README）。
3. **填页面**：文案与字段照抄 `docs/发布/N网发布文案.md`（里面有 Short description 的中英两版、
   完整中文正文、英文简版正文、以及 Category / Version / Permissions / Credits / Images 的建议）。
4. **图片**：至少放 2 张截图，现成的在 `docs/素材/界面改版/`：
   `06_合理度_全部混合.png`、`07_合理度_各自随机.png`、`08_方案库详情.png`。
5. **先存草稿**：N网 有审核/发布确认流程，建议先 *Save as draft* 自己预览一遍，
   确认"下载 → 解压 → 丢进 MOD 根目录 → 双击"这条链路在你机器上没问题，再点发布。

### N网 容易踩的点

- 上传包**不要**包含法魂本体（MOD 文件）或游戏原始文件 —— 这个包里只有工具、说明与 README。
- 如果 N网 提示"文件类型不允许"：确认 zip 里没有 `.dll`（本工具是单文件 exe，不带 DLL ✓）。
- 版本号写 `1.0.0`；以后改版用同一页面的 *Upload new version*，别新建一条 mod 页。
