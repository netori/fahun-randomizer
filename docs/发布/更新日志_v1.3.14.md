# 更新日志 v1.3.14（2026-10-24）

> 一句话：**所有多阶段 Boss 现在都能当来源** —— 玛莲妮亚、拉达冈 / 艾尔登之兽、梅瑟莫、蕾娜菈、
> 拉卡德、荷莱·露、火焰巨人……这些以前「只作为位置、从不作为换入者」的 Boss，现在也能被抽到别的位置上。
> **默认开**，界面可关；旧预设不用改。

---

## 一、为什么改

作者原话：「我要求所有多阶段的boss都可以作为来源，你看看参考mod怎么做的呗，它都能做到，理论上我们也能做到」。

原因：多阶段 Boss 的位置从 v1 起一律 **keep**（换掉其中一个阶段 = 半只 Boss，转阶段/死亡事件会断），
所以它们的身份也进不了来源池 —— 无论怎么调来源百分比，来源里永远只有单阶段 Boss。

参考实现（thefifthmatt 的 Elden Ring Enemy Randomizer）能做到，靠的是四件事（源码拆解见
`docs/参考实现_拆解/A_主流程与分类学.md` §4.2–4.4、`docs/参考实现_拆解/B_敌人写入与ER专属.md` §4）：

1. **每个阶段都是独立 source**：`NextPhase` 建立 multiPhase 映射（`EnemyRandomizer.cs:1620-1650`）；
2. **只有「双方都是多阶段实体」才要求同相位配对**，单阶段目标可以接受任意相位来源
   （canPlace 规则 16，`:1895-1909`）；
3. 阶段预算（SourcePhases / TargetPhases + BossPhaseLimit）；
4. 每个 Boss 提供一份 EMEVD 事件段契约（`EventConfig.cs:225-239`）。

我们只搬运「四元组身份」（model / npc / think / chara + 参数数值），目标位置又都是单阶段位置，
不需要相位配对，也不搬那只 Boss 自己的事件脚本 —— 所以取「身份本身能独立出战」的实体就够了。

### 2）计划层：新约束 `constraints.multiphase_as_source`（默认 `true`）

- 新函数 `multiphase_source_units()` 把「组 → 可当来源的单元」标出来；
- `donor_units(..., extra_ok=...)` 允许这些 keep 单元进**来源池**，但仍走全部资格过滤
  （模型黑名单、think ≤ 0、hp ≤ 0、c0000、Sound 排除等）；
- **位置侧不受影响**：多阶段位置仍然 keep，随机不会去换那一场战斗
  （想换那一场战斗用「多阶段BOSS整组替换」，那是另一件事）；
- `meta.counts.multiphase_sources = {enabled, units, groups}`，关掉 = 0；
- 来源池 **22,183 → 22,207（+24）**。

### 3）界面

- 敌人页新勾选框「**多阶段BOSS也能当来源**（默认开：玛莲妮亚 / 拉达冈 / 艾尔登之兽 / 梅瑟莫 等可以换到别处）」；
- 「编辑逐类预设」右栏同款勾选；
- `--uitest` 新增 2 条断言（默认开进 options / 关掉为 False）。

### 4）特殊池联动

这些多阶段身份本身带池标签（追忆池 / 楔石池），所以预设里来源写 `pool:remembrance`、`pool:keystone`
时，多阶段 Boss 也会出现在来源里 —— v1.3.13 时「池 Boss 当来源」看不到多阶段 Boss 的观感问题，本版一并解决。

### 5）兼容性

- 旧预设**不用改**；不重建位置表 / 数据表（yaml 只加字段，数据仍 27,780 行）；
- 注意：yaml 参与计划种子的指纹 —— **同一个 seed 在 v1.3.14 会生成与 v1.3.13 不同的计划（全量重排）**。
  想要和上一版一样的组合，请沿用旧版已生成好的计划 / 方案层。

## 三、升级

换 exe 即可。旧预设、旧方案层照常能用。不想让多阶段 Boss 当来源：敌人页把勾去掉
（等价于 `constraints.multiphase_as_source=false`）。

## 四、边界

- **只换身份，不搬事件**：换到别的位置的是那只 Boss 的模型 / AI / 数值；目标场地仍跑原来的
  雾门、死亡、奖励、剧情事件。
- 二阶段身份（如艾尔登之兽、腐败女神）单独拿来当单阶段 Boss 时，依赖转阶段事件的演出不会发生
  —— 与现在单阶段 Boss 当来源是同样的限制。
- 真身被事件绑定的（幽影树化身 / 米德拉 / 融泥骑士）只取本体身份；血条助手、坐骑、事件共用体不当来源。
- 「能当来源」≠「那个位置会换」：多阶段位置仍然 keep。
