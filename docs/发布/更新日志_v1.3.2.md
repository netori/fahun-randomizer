# 更新日志 · v1.3.2（2026-10-23）

> 这一版把「生成」和「写入」**收成一个按钮**。上一版 v1.3.1 是界面重排（删死表单、动作按页走）。
> 随机引擎、写盘逻辑、方案与存档仍然一个字节没动 —— 旧方案层可以直接继续开局。

## 一、一个「开始随机xxxx」

- 窗口底部原来并排的 **「① 生成随机方案」+「② 写入游戏」** 合成一个金色主按钮，文案跟着勾选变：
  - 只勾职业物品 → **开始随机物品**
  - 只勾敌人 → **开始随机敌人**
  - 两个都勾 → **开始随机物品和敌人**
  - 都不勾 → 按钮变灰，提示先勾选类型
- 点一下就是**生成 + 写入一次完成**：物品方案生成完自动接着写入；物品 + 敌人则在同一次生成后建层并挂载。
- 写入前仍会**弹一次确认**，列出这次会写什么；点「否」什么都不写（结果留在「这次会改什么」里，种子不变时再点是同一套）。
- 底栏在**敌人页也显示**了（上一版收起来过）：因为主按钮现在只有这一个，不该跟着页签躲。
- 敌人页左卡只剩 **「预览这次会换什么（不写盘）」**；原来那三个重复的入口（生成方案层并应用 / ①+② 一次写 / 写入方案层）全部删除。

## 二、验证

- 界面自检：--uicheck（构建 + 12 项对比度 + 装饰件 5/5）、--uitest 全绿；
  新增断言：主按钮全窗口唯一、四种勾选组合的文案与禁用状态、点击后按勾选分派到「只物品 / 只敌人 / 组合」、
  底栏在敌人页可见而在方案库页收起。
- 端到端冒烟：只勾物品 → 点一次 → 8.2 秒后出「✓ 方案层已就绪（法魂本体未改）」，
  Plan= 自动挂到新层，法魂本体文件 SHA 不变。
- 引擎自检：--selftest、--planlib 全过。

## 四、升级注意

- 覆盖旧 exe 即可；`plans\`、`存档库\`、已生成的方案层都不动。
- 流程图变短了：以前是「生成 → 看一眼 → 写入」，现在是「点一次 → 确认框里看一眼 → 确认」；
  想在确认前细看结果，就在确认框点「否」，结果会留在「这次会改什么」里。
