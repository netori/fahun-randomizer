# 界面改版：照参考实现重塑（2026-10-21）

## 0. 三句话

参考实现 thefifthmatt/SoulsRandomizers 的 ER 界面是「顶部页签带启用勾 + 多列分组框 + 底部固定种子/开始/启动/状态」的密集表单；
这次保留我们的暗金主题与全部功能，把**信息架构**改成同一套：页签勾选、两列分组、底部固定动作栏、旧管线折叠。
功能一个没少，`randgui.py --uicheck` / `--uitest` 全绿。

## 1. 参考实现的结构（源码依据）

源码：`EldenRingRandomizer.Avalonia/Views/MainWindow.axaml`（sparse 检出在临时目录，不随仓库分发）。

| 位置 | 参考实现的做法 | 我们的对应 |
|---|---|---|
| 顶部 | 菜单条（File / Options / Language），没有大标题 | 压成一行品牌条：图标 + 名称 + 环境状态 |
| 页签 | TabItem 头里放 CheckBox + 标题；勾掉 = 整块功能关闭、标题划线/变灰 | 物品 / 敌人两个页签各带一个勾，方案库没有 |
| 页内容 | `ScrollViewer` + 3 列 `Grid`（17*/7/17*/7/18*）+ 一批 `HeaderedContentControl` 分组框 | 两列分组：物品页「随机项目 / 结果」、敌人页「v1 / 方案层 + 预览」 |
| 底部 | 游戏路径、合并 mod、消息、Seed + Reroll seed、大 Randomize、Launch、状态条 | 种子 + 每次重掷 + ①生成 / ②写入 / 还原 / 保存方案库 + 启动游戏 + 状态条 |

参考实现里的「Game progression / Misc / Enemy placement」是敌人页的分组名；我们的旧管线本来就按这组名字做的，这次把它折叠起来，让 v1 卡片当主分组（eyebrow 改为「敌人摆放」）。

## 2. 这次改了什么

1. **顶栏压扁**：去掉三行大标题区，改成一行（30px 图标 + 「法魂随机器」+ 一句副标题 + MOD/引擎 chip）。参考实现没有 hero，密集表单不需要它。
2. **页签带启用勾**：
   - 物品页签勾 = `item_on`；取消后底部「① 生成 / ② 写入」禁用，页签标题变灰。生成/写入函数里也有闸门（防止脚本绕过）。
   - 敌人页签勾 = `ev1_on`；取消后 v1 卡片里的池/滑块/预览/部署/挂载全部禁用，点按钮会提示先勾页签。
   - 方案库不是随机功能，没有勾。
3. **底部固定动作栏**（照参考实现的 Seed / Randomize / Launch / Status）：
   - 种子输入从物品页搬到窗口底部，和「每次生成时重掷」放一起；
   - ① 生成（金色主按钮，加宽）、② 写入、还原成原始、保存到方案库；
   - 右侧「启动游戏」：直接运行法魂包根目录的 `启动法魂.bat`（等价于参考实现的 Launch Elden Ring）。
4. **两列分组**：
   - 物品页：左「随机项目」、右「这次会改什么 + 小提示」；合理度、本地文件、更多设置、详细记录仍全宽。
   - 敌人页：左 v1 规则矩阵（池 / 多阶段 / 种子 / 比例 / 操作 / **六条规则说明**），右「方案层 + 预览」。
5. **旧管线（v0）折叠**：默认收起，只留一行「▸ 旧管线（v0，已停用）— 展开看看」；展开后仍是参考实现那套「游戏进程 / 敌人摆放 / 法魂专属 / 规划中」分组。旧控件全部保留（测试与兼容都靠它们），只是不再占默认版面。
6. **窗口高度按屏幕夹一次**：高 DPI 下 `px(820)` 可能超过屏幕，底部种子/按钮会被任务栏盖住；现在最多占屏幕 90%，保证底栏永远可见。
7. **卡片内边距收紧**（`_card` 默认 pad 20→16，标题/内容间距同步减 2–3px），一屏能多看一组。
8. **逐类预设编辑器**（2026-10-21 晚补）：v1 卡片「编辑逐类预设…」打开左树右面板的窗口（16 类 + 4 池 + 全局），可保存/载入 JSON；详见 `docs/敌人随机_逐类预设与分类对照.md`。

## 3. 语义（不是装饰性勾选）

| 控件 | 变量 | 关掉以后 |
|---|---|---|
| 物品页签勾 | `item_on`（默认 True） | 底部 ①/② 禁用；`generate()` / `deploy()` 直接提示并返回；敌人 v1 不受影响（它有自己的部署按钮） |
| 敌人页签勾 | `ev1_on`（默认 True） | v1 卡片内所有可点控件禁用；`enemy_v1_preview/deploy/launch/revert` 提示「先勾页签」 |
| 每次生成时重掷 | `reroll_seed`（默认 False） | 勾上后每次点 ① 先 `_dice()` 换种子 |
| 旧管线折叠 | `enemy_legacy_open`（默认 False） | 展开/收起，不改变任何配置 |

## 4. 保留的东西

- 暗金配色、卡片描边、金色下划线导航、自绘 `GoldCheck` / `Switch` / `NavBook`；
- 三页签（职业物品随机 / 敌人随机 / 方案库）与方案库全部交互；
- 物品侧的 ① 生成 / ② 写入 / 还原 / 保存方案库；
- 敌人 v1 的四池、比例、多阶段实验开关、预览/部署/挂载；
- 所有旧敌人管线控件（只是折叠）。

## 5. 验证

- `python randgui.py --uicheck` **PASS**：12 项对比度全 OK（主文字 15.14、次文字 8.29、金标题 9.54…），亮块 0 处，页 1 控件 21/21。
- `python randgui.py --uitest` **PASS**，新增 10 条断言：
  - 页签启用勾：物品与敌人各一个、方案库没有；
  - 物品勾掉 ⇒ 底部 ①/② 禁用；勾回 ⇒ 恢复；
  - 敌人勾掉 ⇒ v1 部署/预览禁用；
  - 种子输入框在底部、不属于任何一页；
  - 底部有「启动游戏」；
  - 旧管线默认收起 / 能展开 / 能再收起。

## 6. 已知边界

- 没有照搬参考实现的顶部菜单条（File / Options / Language / 更新检查）：我们没有多语言、更新检查与 uxm/me3 安装选项，硬加会是空菜单。
- 页内容还是「卡片」而不是 WPF 的分组框：视觉语言保留暗金，只对齐信息架构与密度。
- 参考实现的每类百分比是预设编辑器里的 Weight/AdjustSource；我们的逐类编辑器已经补上（2026-10-21 晚，见 `docs/敌人随机_逐类预设与分类对照.md`）：v1 卡片「编辑逐类预设…」，16 个类各自设开关/换入权重/目标类/区域/体型上限（权重叠加，和参考 mod 的 pool Weight 同义）。
- 「启动游戏」依赖法魂包根目录存在 `启动法魂.bat`；找不到会弹错误，不会静默失败。
- 旧管线折叠只是默认收起，代码与控件都还在；按计划 v0 不再参与主部署。
