# 二阶段携带「加载即死」诊断记录（2026-10-26）

用户原话（m20827 / m21281）：「我还没见到他他就死了」/「还是死了，没见到梅瑟莫他就死了」。

## 一、现象（已复现，截图可证）

快速试玩层：法魂包\方案\试玩_梅瑟莫二阶段_引导之始\mod
（引导之始大树守卫 m60_42_36_00 entity 1042360800 换成梅瑟莫一阶段 + 克隆二阶段 part 1042361982 + 3 个新事件）。

用验证 F 档（3EDF2114186CB926，角色在艾雷教堂一带）加载 → **世界加载完的瞬间**弹出金色「ENEMY FELLED」横幅，
右上 +3200 卢恩，随后获得「女猎手的刺剑」x1（= 地图公共事件 itemLot 30100 的产物）。
（原始截图在 2026-10-26 整理磁盘时已删；复现方式见 §六 第 1 步的抓图脚本 investigation\_probe\phase2_carry\capture_shot_enter.ps1。）
即 Boss 在玩家还没走到之前就已经死了，且死亡结算链路（横幅 / 卢恩 / 道具）是正常的。

## 二、对照实验矩阵（截至停手）

| 变体 | 内容 | 结果 |
| --- | --- | --- |
| 纯换层 | 只有 MSB 换模型 + regulation +1 行 + 血条名，无克隆 part、无新事件 | **Boss 活着并主动用火焰技打玩家**，无横幅（frames_pure）|

| 变体 D | transition 事件整条换成单条 END（只留 init+death）| 试验作废：卡在标题 / 进了显示选项菜单，没抓到世界加载 |
| 变体 E | death 事件整条换成单条 END（只留 init+transition）| 未测完（两次跑到 run_code 120s 超时 / 中止；frames_ve 可能有半截帧）|

⇒ 方向已定：**加载即死由「克隆 part + 3 个新事件」引入，换模型本身无罪**。

## 三、头号假设（下次第一件事就是验它）

地图事件 0 会调 common_func 的 **90005860「野外 Boss 死亡结算」**，入参里的实体是**一阶段 1042360800**。
该公共事件的编译后逻辑（40 条指令，已 dump）是：

1. 若击败 flag 已置位 → 静默 Kill 并结束；
2. 否则 WaitFor(CharacterHPValue(phase1) <= 0) → 播 SFX → WaitFor(CharacterDead(phase1))
   → HandleBossDefeatAndDisplayBanner（ENEMY FELLED）→ 给玩家 SpEffect 3450 → 置击败 flag → AwardItemsIncludingClients(itemLot)。

我们的 death 事件是「等二阶段死亡 → 开一阶段 → Kill(一阶段)」。
如果引擎对被禁用（disabled）的实体把 CharacterDead / CharacterHPValue 读成「已死 / 0」，
那么 init 事件在加载时禁用二阶段 → death 事件的 WaitFor(CharacterDead(phase2)) **立刻成立**
→ 立刻 Kill(phase1) → 地图的 90005860 看到 phase1 已死 → 横幅 + 卢恩 + 道具。**与现象完全吻合。**

另一条同样能造成加载即死的路径：transition 的 HPRatio(phase1) <= 0.5 在实体尚未生成时读成 0
→ 加载瞬间关掉 phase1、打开二阶段 → 90005860 同样判定 phase1 已死 → 横幅。变体 E 就是用来排除这条的。

## 四、顺带发现的设计缺陷（比加载即死更根本）

野外 Boss 的结算入口 90005860 **只盯地图自带的那个实体（一阶段）**。
所以就算加载即死修好，「transition 关掉一阶段」这一步也会让 90005860 在玩家刚打完一阶段时就判定战斗结束
（横幅 + 发奖），二阶段白做。可行修法二选一：

- **A（推荐）**：补丁地图事件 0 里 InitializeCommonEvent(90005860) 与 InitializeCommonEvent(90005870) 的入参，
  把实体换成二阶段 1042361982、血条名换成 905130001；同时删掉自定义 death 事件（不再需要它收尾）。
- **B**：transition 时不禁用一阶段，改为传送走 / 设无敌，二阶段死了再由 death 事件 Kill(一阶段) 收尾。

方案 A 更贴近 vanilla（vanilla 梅瑟莫有自己的地图事件，不依赖这个通用 handler）。

## 五、已确认的硬事实（省得下次重查）

**事件指令编码（EMEDF + vanilla 字节双证）**
- (1003,2) EndIf(EventFlag) 8 字节；word0 = 0x00000100 表示「flag=ON 就结束/等待」（byte0=0，byte1=1）。
- (3,0) IfFlagState 8 字节；vanilla WaitFor(EventFlag(1042368540)) 的字节是 00 01 00 00 1c 48 21 3e。
- (4,0) IfCharacterDeathState 16 字节 = (条件组, 实体, is_dead, 1.0f)。
- (4,2) IfHealthRatioComparison 24 字节 = (条件组, 实体, cmp=5(<=), ratio f32, 0, 1.0f)。
- (4,14) CharacterHPValue 比较 24 字节 = (条件组, 实体, cmp, value f32, 0, 1.0f)（90005860 用的就是这条）。
- (2003,11) DisplayBossHealthBar 16；(2003,66) SetEventFlag 12 = (0, flag, state)；(2004,4) Kill 8 = (实体, award_runes)；
  (2004,5) SetCharacterState 8；(2004,8) AddSpecialEffect 8；(2004,21) ClearSpEffect（(2004,7) 是 CreateBulletOwner）；
  (2004,26) ChangeCharacterDispmask 8；(2004,34) SetNetworkUpdateRate 8；(2003,18) ForceAnimationPlayback 16；(2010,2) PlaySE 12。

**工具 API**
- evd_edit.load_evd(path) → (Evd, dcx_meta, raw)；Evd.events 是 **list**（dict：idx/eid/icnt/ioff/arcnt/aoff/rest/pad）；
  Evd.instructions(eid) → [(j, cat, idx, size, aoff)]；参数在 raw[ev.arg_base + aoff : aoff+size]。
- evd_add.add_events(raw, specs, register=True)；msb_write.dcx_repack(raw, in_kind=..., out_kind="right", ...)。
- 法魂包 mod\event\ 下有 267 个 .emevd.dcx.js **明文**（含 common、common_func），查语义比反编译快得多。

**实机测试环境（踩过的坑）**
- 启动：只有 cmd /c "启动法魂.bat"（工作目录=法魂包根）能起；直接 yafsml\YAFSML.exe --game-path 会静默退出。

  → 要可靠换档就把 76561197960271872\ER0000.cnv 直接覆盖成目标档，再用 cmd /c 启动法魂.bat 启动。
- 截图：独占全屏抓不到画面；GraphicsConfig.xml 是 UTF-16 LE，把 <ScreenMode>FULLSCREEN</ScreenMode> 改成 WINDOWED
  后窗口 0,0 1707x1067 可 CopyFromScreen 抓图；**游戏退出时会自己把 ScreenMode 写回 FULLSCREEN，每次测试前要重打**。

- 标题画面有时停住不自动进游戏；需要在游戏窗口前台时注入 Enter（SetForegroundWindow + keybd_event(0x0D)）。
- 存档：验证 F 档 3EDF2114186CB926（Boss 活着）；试玩槽已被回存成新角色档 DCAA978E714C0FBF。

## 七、教训

- 实机验证先做单变量：这次「纯换层活着 / 带克隆+事件就死」一刀切开，比反复猜指令编码值钱得多。
- 「加载即死」优先怀疑通用公共事件（90005860 这种）的入参，而不是自己新写的事件编码。
- 截图 / 前台窗口 / 存档换档这些环境因素会伪装成「功能坏了」：先证明眼睛看到的是游戏真实状态，再谈代码。
- PowerShell 脚本写盘必须带 UTF-8 BOM，否则中文路径被按 ANSI 读成乱码直接语法报错。
- run_code 默认 120 秒截止；跑几分钟的实机脚本必须显式传 timeoutMs。
