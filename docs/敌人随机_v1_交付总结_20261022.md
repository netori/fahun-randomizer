### 1.8 区域缩放：换入者整行 + source→target SpEffect（2026-10-22 23:0x 实现，23:3x 主层已重建并挂载）

- **paramdef 补上了**：ER 的表名与定义文件名不一致，`SpEffectParam` 实际读 `SpEffect.xml`；`enemy_randomizer.paramdef_fields` 加别名后 `FieldBook("SpEffectParam")` 可直接按字段名读写（行大小 907 / payload 912）。
- **实现**：每个位置已有独立克隆行，因此不像参考实现那样改 EMEVD，而是把一条自定义 `SpEffectParam` 挂到克隆行第一个空着的 `spEffectIDN`（跳过 `spEffectID3`），倍率按 source/target 两个标准十步档的 health/damage/defense/buildup/xp 字段算 target/source。
- **source 中性**：source 只看换入者自己的 `spEffectID3`；换入者为 0/非标准时记 1.0，不拿地图档替它补一个不存在的源倍率。这是本轮修掉的真 bug（否则换入者无档时实际 HP 会掉到约 1/10）。target 才允许同地图标准档众数兜底；19 张没有标准档的图保持中性。Boss→杂兵（`b2m`）的 health/xp 再乘 0.25。
- **计划层同步**：HP 默认换入者；普通→Boss 且原位置更厚时 `sqrt(原×换入)`；魂默认仍位置原值。旧的「hp 写位置原值」模型从新层起改为换入者整行。
- **实测**（预设 `01 参考默认·同族池`，seed 20261010）：497 图 / 24,421 位置 / 22,470 单元；NpcParam 7,830 → 25,963（+18,133 克隆）；19,728 个单元挂 area SpEffect / 343 条自定义行；b2m 27；档位使用两侧合计 直取 36,137 / target 地图兜底 4,310 / 无档 4,493；`--verify` PASS、`enemy_gate --offline` PASS（677/677），区域倍率逐条算术复验 **0 失配**。
- **档位能不能当难度参考**：能当**相对区域倍率**（标准档的 health/attack/defense 严格单调；同档内基础 HP/类别仍决定绝对强度），不能当**绝对单敌难度**。Spearman：Basic 0.553 / Wildlife 0.906 / Mob 0.616；地图级 0.731。特殊档（7130、7131–7151、1935x、200072xx/200073xx）已排除。
- **主层已切换**：2026-10-22 23:3x 用同一份计划（`敌人v1_区域缩放_物品+敌人_种子20261010_1022_2325.json`）从**已含物品改动的本体**重建了 `方案\敌人v1_区域缩放_物品+敌人_种子20261010_1022_2325` 并挂载；物品表与本体逐字节一致、层里没有 `msg`，说明书仍读本体那份。旧合并层 `敌人v1_物品+敌人_种子20261010_1022_1942` 保留，可切回。
- **边界**：阶段缩放 spEffect（1.4/0.7）仍未接；测试层 `实验_区域缩放_seed20261010` 保留但已不是当前挂载层。完整数据依据见 `docs/敌人随机_区域档位依据_20261022.md`，写盘细节见 `docs/敌人随机_M2_写盘层报告.md` §7.19。
