## 2. 已接功能怎么用（GUI）

敌人随机页 →「敌人摆放」卡片：

1. **特殊池**：黄金树传送门 / 大锅钥石 / 追忆 / 劳弗圣龛；关掉 = 该池位置保持原样（仍可当来源）。
2. **多阶段BOSS位置**：**v1.3.15 起默认换、不提供开关** —— 14 组全换；**v1.3.16 起按「模型」拆 Boss**：
   同一模型（跨阶段 / 多管血条）算一只、整组共用一个换入身份，不同模型拆成多只各自随机（14 组 / 20 只 Boss /
   33 个位置）。此前 v1.1–v1.3.14 是「实验、默认关、只换 5 组无 pair 的」，见
   `docs/发布/更新日志_v1.3.15.md`。
3. **改BOSS血条名 / 夜间BOSS全天出现 / 忽略场地·体型限制**：写盘层消费。
4. **BGM跟新BOSS / 卢恩跟新BOSS**：克隆行 threatLv / getSoul 跟捐赠者（默认关 = 保留位置原值）。
5. **生命值倍率**：0.5–2.0×，乘到克隆行 `target_hp`；不改变「位置原值对齐」的语义，只是整体再缩放。
6. **全替换为**：选一个类别（常规敌人 / 主要BOSS / …）；所有可随机位置都换成该类，其它规则/预设让位。
7. **逐类来源百分比（新）**：自定义敌人配置里，每个目标类各有一组来源百分比，合计 100%；可以多个来源叠加（如常规敌人 = 80% 常规敌人 + 20% 主要BOSS），不同目标类互不影响。
8. **种子 / 比例**：种子固定可复现；比例是「有多少位置参与替换」的全局倍率。
9. **自定义敌人配置…**：逐类预设编辑器（每个目标类一组来源百分比 + 自动平衡 / 独立概率 / 来源区域 / 目标区域 / 体型上限 / 特殊池 / 多阶段开关 / 一键「合并全BOSS」「合并全敌人」）。
10. **手动指定…**：打开 `investigation/enemy_manual.csv`，每行一个位置：`map,entity_id,npc_id,model,note`；`npc_id` 与 `model` 二选一。只作用于 `policy=randomize` 的位置（keep/脚本绑定位置不碰），优先级高于池/规则/比例；找不到目标捐赠位置会在负向账本里记 `manual:no_donor`，不会偷偷退回随机。实测：`m10_00_00_00 / 10000850` 指定 `npc 58100084` → 写出层里该 part 变成 `model c5810 / npc 58100085`（克隆行），`--verify` PASS。

- **9 类可见**：参考 10 类按法魂模型名重算；法魂新增无名杂兵并入常规敌人（`class_aliases: {Mob: Basic}`），
  未分类 / 随从召唤物 / 复制体 / 假人测试体 / 粪金龟 / 商队巨魔 6 类标 `ui: false` 退场（见 v1.3.12）。
- **四个池**：楔石 18 成员（13 Boss / 5 组）、追忆 48 成员（32 件追忆，多阶段逐阶段）、传送门 28 成员、劳弗圣龛 1 成员（9 个仪卫变体共用竞技场实体，keep）。
- **多阶段 14 组**：v1.3.15 起全部默认换（含 pair 组）；v1.3.16 起按模型拆成 20 只 Boss —— 同模型整组共用一个身份，
  异模型各自独立随机。pair 组仍按「整场一只」处理（安塞尔河坏档同源风险，已显式认账 `pair: true`）。
- **重复 MSB**：2,124 组 / 4,248 行 = 25,656 个物理位置；同一物理位置两份图必须同步替换（计划层已保证）。
- **位置级数值对齐（旧模型，19:4x 层 / 回滚层）**：克隆行抄位置原 `hp` / `getSoul` / 防御 / 抗性 / 韧性 / 掉落；攻击走位置原 `spEffectID3` 档。这是旧主层「任意类互换但不崩难度」的做法。
- **区域缩放（2026-10-22 23:0x，23:3x 已挂载主层）**：改为换入者整行 + 一条自定义 `SpEffectParam`，按 source 档（换入者自己的 `spEffectID3`）→ target 档（位置档/同地图众数）缩放 health/damage/defense/buildup/xp；普通→Boss 用 `sqrt` 桥接，Boss→杂兵 health/xp×0.25。当前挂载 `敌人v1_区域缩放_物品+敌人_种子20261010_1022_2325`。

## 6. 当前限制（如实）

1. 「生命值倍率」只改 HP；伤害/防御按档位缩放（参考是同一倍率同时改血/伤）。**当前区域缩放主层已按档位一起缩放 damage/defense**；旧合并层仍是位置原值模型，可回滚。
2. 「BGM跟新BOSS」是 threatLv 跟随，不是逐首 BGM 表；野外模板的 BGM 判定已中性化，所以血条不会再被 BGM 卡住。
3. **敌人倍增是实验子集**：只复制普通敌人 part，不给复制体写独立事件；依赖 EMEVD 按实体 ID 的脚本（个别巡逻/出场）不会覆盖复制体；默认关。
4. 「全替换为」是**类级**（所有位置 → 某一类），不是参考的「单一敌人种类」；要单一模型得等模型级手选。
5. 多阶段整组替换仍是实验开关，默认关。
6. 「合并类别」在每个目标类的来源百分比里把多类设成同一来源；全局页也提供一键「合并全BOSS」「合并全敌人」（写成等分来源）。
