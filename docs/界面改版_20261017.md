## 2. 设计口径（为什么这么改）

- **底色压暗一档**（`#131009`），金只留三处：主按钮、页标题眉标、选中下划线 —— 到处是金等于没有金。
- **用描边 + 留白分组**，不用浮雕边框：暗底上 1px 细线 + 16~20px 内边距比立体边框干净。
- **字分三档**：主文字 `#ece5d6` / 次文字 `#b6aa94` / 三级文字 `#8e8473`；说明文字不再和主内容抢视线。
- **权重靠明度排**：一屏最多一个金色主按钮；「写入游戏」在生成成功后才升为主按钮。
- 保留原来的法环味（暖黑 + 旧金 + 徽记），但把装饰从"每条分隔线上放藤蔓"收敛到顶栏一枚徽记。

对比度全部由 `--uicheck` 的 `CONTRAST_REQUIREMENTS` 守住（正文 ≥10:1、次文 ≥8:1、
三级文 ≥4.5:1、金主按钮文字 ≥4.5:1、禁用态 ≥3.5:1）。

## 4. 新增的界面积木（`randgui.py`）

- `_card(parent, eyebrow, title, desc)`：1px 描边卡片，返回 `(外壳, 内容区)`。
- `_page_head(...)`：每页的「眉标 + 大标题 + 一句说明」。
- `_chip(...)`：细描边小筹码（状态 / 标签 / 规划中）。
- `Switch`：Canvas 双态胶囊开关，支持 `configure(state=...)`。
- `GoldCheck`：Canvas 自绘勾选行，接口与 `ttk.Checkbutton` 的常用子集对齐
  （`text / variable / command / state / width / invoke()`）。
- `NavBook`：替代 `ttk.Notebook` 的页面容器（保留 `select/tabs/tab/add/bind` 接口），
  这样导航条可以自己画，而旧的调用点一行不用改。
