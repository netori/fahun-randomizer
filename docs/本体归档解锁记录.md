作者问「真的只能解包本体文件名」—— 方向对，而且这轮把**加密那一步拿下了**。

## 找到的东西

* **密钥**：`JKAnderson/BinderKeys` 仓库 → `EldenRing_PC/Key/Data{0,1,2,3}.pem` + `DLC.pem`（RSA 公钥，438 字节）
* **文件名词典**：同仓库 `EldenRing_PC/Hash/Data{0,1,2,3}.txt` + `DLC.txt`（哈希 → 路径）
  —— 这就是「本体文件名」，**不用解 50 GB**
* 这两个来源是 WitchyBND / Nuxe 的官方依赖（Nuxe 的 `.gitmodules` 里就指着 BinderKeys 仓库）

## 已经验通的

1. **`.bhd` 是 RSA 加密的，能解开** ✅
   每 256 字节一块，用对应 `DataN.pem` 的公钥做模幂（`pow(blk, e, n)`）→ 明文
   实测五个文件全部成功，明文开头是 `00 42 48 44 35`（**1 字节前缀 + 'BHD5'**，
   难怪之前直接搜 `BHD5` 搜不到、BinderTool 那套也判不出来）

2. **头布局（实测对出来，与 BinderTool 的 DS2/DS3 排法不同）**
   ```
   +0x00  1 字节 \x00
   +0x01  'BHD5'
   +0x05  i32 版本（Data0 = 511）
   +0x09  i32 未知（1）
   +0x0d  i32 大小
   +0x11  i32 桶数（Data0 = 839）
   +0x19  i32 盐长度（8）
   +0x1d  盐（"GR_other"）⇒ **桶目录紧随其后（0x25）**
   桶：每桶 **8 字节** = i32 条目数 + i32 条目表偏移（实测 6748 / 7028 / 7228…，都在文件内）
   ```
