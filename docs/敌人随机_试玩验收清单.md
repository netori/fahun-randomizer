## 7.6 参考实现对齐的新开关（这一层默认都没开）

v1 卡片新增三项（改完要重新「预览 → 写入方案层」才生效）：

- **生命值倍率**：0.5–2.0×，乘到克隆行 HP；伤害/防御仍按位置档。
- **全替换为**：所有可随机位置 → 同一类（类级 Oops All）。
- **BGM 跟新BOSS / 卢恩跟新BOSS**：克隆行 threatLv / getSoul 跟捐赠者；默认关 = 保留位置原值。
- **预设编辑器**里新增「合并全BOSS」「合并全敌人」两个一键按钮（参考实现的 Quick edit 语义：把一组类别并成同一个池）。
- **手动指定…**：打开 `investigation/enemy_manual.csv`，按 `map,entity_id,npc_id,model,note` 填；只动可随机位置，优先级最高。
- **随机化敌人颜色**：默认关；勾上后向 MaterialExParam 追加 12 行纯色，克隆行第一个空材质槽指向颜色。模型是否明显变色取决于它是否用那个材质槽。
- **敌人倍增（实验）**：默认 1.0=关；1.5≈+50%，2.0=+100%，上限 2.0（GUI）。只复制普通敌人（常规/野生动物/法魂杂兵/粪金龟）的 part，Boss、传送门、多阶段、有血条、池成员一律不复制；复制体偏移 2.5m、沿用同一个克隆行。风险：复制体没有独立事件，个别依赖脚本的巡逻/出场可能不生效。想直接看效果可挂独立层 `方案\实验_倍增_seed1`（1.5×，2,721 个复制体，离线复验 PASS）。

另外「夜间BOSS全天出现」「忽略场地/体型限制」「改BOSS血条名」已在卡片上；参考实现的功能对照见 `docs/敌人随机_参考功能对照.md`。
