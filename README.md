# 法魂职业道具和装备随机器（THE COVERAGE · Elden Ring 1.17.1）

给「法魂」MOD 用的物品随机化工具：**只换物品、不搬位置**，随时可一键还原。
原生实现，**不依赖任何外部工具**（自研 AES / DCX / Oodle / BND4 / PARAM / FMG 读写）。

## 功能

- **随机项目**：卢恩 / 护甲 / 装备（自由勾选，至少一项）
- **混合方式**：全部混合（一起混）／各自随机（各随各的）
- **合理度 0~100%**：控制「跨档位混合比例」与「装备掺入混池比例上限 66%」
  - 100% = 只同等级互换，装备不掺入；0% = 等级完全放开
- 法师/祷告护甲**始终单独一组**，绝不与近战混合
- 同一种子 = 完全一样的结果；不同种子 = 不同结果
- 说明书（职业说明书文本）跟着一起改：**物品名不动，只改它现在所在的地点**

## 用法

1. 把游戏目录（含 `mod/regulation.bin` 与其 msg 目录）准备好，工具放在 MOD 根目录
2. 双击 `法魂职业道具和装备随机器.exe`（或 `python randgui.py`）
3. 选随机项目与混合方式 → 拉合理度 → 填种子 → 点 ① 生成随机方案 → 点 ② 写入游戏
4. 不满意：点「还原成原始」

命令行：
```
法魂职业道具和装备随机器.exe --deploy <plan.csv> [--no-guide]   # 只写入，不开界面
法魂职业道具和装备随机器.exe --selftest                          # 自检（同种子一致 / 换种子不同）
法魂职业道具和装备随机器.exe --uicheck                           # 只构建界面
```

## 关键实现说明

- `regulation.bin` = 16 字节 IV(全 0) + AES-256-CBC → DCX(ZSTD) → BND4 → 各类 PARAM
- **压缩帧必须与游戏一致**：使用 ZSTD `window_log=16`、不写内容长度、不写校验和。
  用 zstd 默认参数（单段 + 内容长度 + 大窗口）**会被游戏解码器拒绝，启动即崩**。
  见 `investigation/apply/_matrix_test2.py` 的「压缩帧校验」（防回归）。
- 只改物品 id 与其类别字段；**数量、概率、价格、库存、解锁、事件流程一律不动**

## 质量保障

- 矩阵测试：15 配置 × 6 种子 = **90 组**（6 项校验 / 守恒 / 可复现 / 法祷零违规）
- 全配置真机验证：每种配置**实际启动游戏**确认能进主菜单（14/14）
- 守恒口径：按「单元」判定（每个单元换走一件、换进一件，整套装备不拆散）
