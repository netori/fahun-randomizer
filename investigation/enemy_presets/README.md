# 敌人随机预设（v1）

这些预设是给「敌人随机」页 →「敌人随机 v1（新管线）」→「编辑逐类预设…」用的。
它们按参考 mod（Elden Ring Randomizer）的 `CustomEnemy.txt` 类池语义改写：
每个目标类有一组**来源类 + 权重**（`donor_weights`），权重会归一化成百分比；
不是全局一个池，也不是“每类只能换同族”。

## 怎么用

1. 打开随机器 GUI →「敌人随机」页 →「敌人随机 v1（新管线）」卡片；
2. 点「编辑逐类预设…」→ 下拉选择上面的文件 →「应用」；
3. 回卡片点「预览（不写盘）」确认替换数量和每类来源占比；
4. 确认后点「② 部署到方案层」；方案层会按当前**本体 regulation** 生成，不会改固定层；
5. 点「用这个方案玩」挂载，完全退出游戏再重进。

预设只影响「计划层」；不点部署就不会写任何文件。要恢复默认，选 `01 参考默认·同族池` 或直接清空自定义。

## 注意

- 参考 mod 的 `CustomEnemy.txt` 只有 Basic/Boss 两个显式池；其余类靠 `MergeParent` / `InheritParent` 继承。这里的七份是我们按同一语义做的**可读预设**，不是逐字节复刻。
- 预设 JSON 里的 `targets` 只是界面显示用的来源类清单；真正消费的是 `donor_weights`。
- 想自己改：GUI 里调完百分比后「保存为…」会写回本目录；文件名就是下拉里显示的名字。
- 与「职业物品随机」的部署顺序见 `docs/敌人随机_与物品随机_兼容性.md`：**物品先写、敌人 v1 后部署**，敌人层会把物品改动一起包进去。
