# 敌人随机预设（v1）

这些预设是给「敌人随机」页 →「敌人随机 v1（新管线）」→「编辑逐类预设…」用的。
它们按参考 mod（Elden Ring Randomizer）的 `CustomEnemy.txt` 类池语义改写：
每个目标类有一组**来源类 + 权重**（`donor_weights`），权重会归一化成百分比；
不是全局一个池，也不是“每类只能换同族”。

## 文件

| 文件 | 思路 | 适合 |
|---|---|---|
| `01 参考默认·同族池.json` | 常规敌人 / 野生动物各自同族；六种 Boss 类共用一个六类等权池（参考的 MergeParent 语义）；粪金龟/商队巨魔/敌对 NPC 不在随机里 | 想接近参考 mod 默认、又不想 Boss 串味 |
| `02 Boss大乱斗.json` | 常规敌人同族；六种 Boss 类共用加权池：主要 40% / 次要 20% / 野外 15% / 夜间 5% / 龙类 10% / 封印监牢 10% | 想每只 Boss 都可能换成别的 Boss |
| `03 杂兵大乱斗.json` | 常规敌人 ↔ 野生动物互混（常规敌人里约 72.5% 常规 + 27.5% 野，野生动物里约 40% 常规 + 60% 野）；Boss 保持同族 | 只想让杂兵热闹，Boss 保持原味 |
| `04 全员大乱斗.json` | 9 个可见类共用同一套加权池（常规 80 / 野 40 / 主要 16 / 次要 16 / 野外 10 / 夜间 4 / 龙 10 / 监牢 6 / 敌对 4；规划层归一化） | 想彻底乱、接受 Boss 也可能变成杂兵 |
| `05 保守半随机.json` | 与 01 相同的池，但每类只替换 50% 位置 | 想保留一半原版体验 |
| `06 全Boss混池·杂兵同族.json` | 六种 Boss 类互抽（等权），常规敌人只随常规敌人、野生动物只随野生动物 | 想 Boss 大乱斗、杂兵保持原味 |
| `07 Boss同类·杂兵同族.json` | 每种 Boss 只换**同一种 Boss**（主要→主要、龙→龙…），常规敌人/野生动物各自同族；特殊池与血条位也用「同类型 Boss」 | 想保留 Boss 的种类感、只换具体是谁 |

> 2026-10-24 起界面只有 9 个可见类：「法魂杂兵」已并入常规敌人（旧预设里的 Mob 百分比自动并进 Basic），
> 6 个无用分类退场（不显示、不当来源）。详见 `docs/发布/更新日志_v1.3.12.md`。

> 这里的百分比是**来源占比**；每类自己的「替换概率」是另一个字段（例如 05 全是 0.5）。
> 权重不必凑满 100，规划层会按比例归一化。
>
> 2026-10-24（v1.3.13）起，预设还能写两个新段：`pools`（四个特殊池当来源/池内位置选来源）与
> `bar`（血条位，覆盖内置的「血条位 → 六类 Boss」规则）。`07` 用了 `@sameboss` 引用：Boss 类位置换成**同一类**的
> Boss，非 Boss 类的真 BOSS 血条位换成任意 Boss 级。详见 `docs/发布/更新日志_v1.3.13.md`。
>
> 2026-10-24（v1.3.14）起**多阶段 Boss 也能当来源**（默认开，`constraints.multiphase_as_source`）：
> 玛莲妮亚 / 拉达冈 / 艾尔登之兽 / 梅瑟莫 / 蕾娜菈 / 拉卡德等 14 组 24 个身份进来源池（22,183 → 22,207）。
> 它们自己的位置仍然 keep；同一 seed 生成的计划会与 v1.3.13 不同。详见 `docs/发布/更新日志_v1.3.14.md`。

## 怎么用

1. 打开随机器 GUI →「敌人随机」页 →「敌人随机 v1（新管线）」卡片；
2. 点「编辑逐类预设…」→ 下拉选择上面的文件 →「应用」；
3. 回卡片点「预览（不写盘）」确认替换数量和每类来源占比；
4. 确认后点「② 部署到方案层」；方案层会按当前**本体 regulation** 生成，不会改固定层；
5. 点「用这个方案玩」挂载，完全退出游戏再重进。

预设只影响「计划层」；不点部署就不会写任何文件。要恢复默认，选 `01 参考默认·同族池` 或直接清空自定义。

> 旧表里的 22,470 / 22,661 等数字是 16 类时代的；2026-10-24 数据重建后按新分类表重算。

所有预设都通过 `EP.validate_plan(plan, data)`（0 错误），构建器无异常。

## 注意

- 参考 mod 的 `CustomEnemy.txt` 只有 Basic/Boss 两个显式池；其余类靠 `MergeParent` / `InheritParent` 继承。这里的七份是我们按同一语义做的**可读预设**，不是逐字节复刻。
- 预设 JSON 里的 `targets` 只是界面显示用的来源类清单；真正消费的是 `donor_weights`。
- 想自己改：GUI 里调完百分比后「保存为…」会写回本目录；文件名就是下拉里显示的名字。
- 与「职业物品随机」的部署顺序见 `docs/敌人随机_与物品随机_兼容性.md`：**物品先写、敌人 v1 后部署**，敌人层会把物品改动一起包进去。
