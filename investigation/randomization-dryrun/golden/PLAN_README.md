# 基准计划（golden plan）

这一份是**冻结的参考输出**，用来检测"引擎行为是否被无意改动"。

| 项 | 值 |
|---|---|
| 文件 | `plan_v1.1_seed20261012.csv` |
| 规模 | 767 行（其中改动 466 行） |
| sha256 | `301fc59ad3c7fe48330ad87766a4d2fe54e7fc8c8d929651b367ad0af1f6a9d6` |
| 引擎版本 | 1.1 |
| 生成配置 | domains=卢恩+护甲+武器；joins=[]；cross_domain=true；coherence=0.8；density=1.0；sets=true；shops=false；basis=guide |
| 种子 | 20261012 |

## 怎么用

```
python investigation/apply/_golden_check.py
```

它用上面的配置与种子**重新生成**一遍，然后与这份基准**逐行对比**：

- **完全一致** → 引擎行为没变 ✓
- **有差异** → 打印差异摘要（多少行、哪些池、几条 old/new 不同），
  说明"这次改动**改变了随机结果**" ✗ —— 如果是有意为之，就更新基准；
  如果是无意的，就是回归 bug ✓

> 注意：基准跟着**引擎版本**走。改了算法并确认新行为正确后，
> 重新生成基准（把新计划覆盖进来，并更新本文件里的 sha256 与引擎版本）。
